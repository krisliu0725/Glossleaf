# Glossleaf／笺：阅读页与书府融合设计 v1

日期：2026-10-31。状态：**设计提案，尚未修改正式应用代码，尚未发布新版本。**

本轮以 0.9.4／0.9.5 的纸墨风格为视觉基线，保留 0.10.0 的实用能力。目标是从书府进入阅读时，仍能认出同一套软件；减少工具和面板的突变，并为后续解决卡顿明确范围。按用户最新截图，**选区轻工具条与右键菜单要合成同一个面板**，轻工具条的外观可以沿用。

## 1. 这次为什么感觉变化太大

书府延续了 60px 顶栏、较舒展的字号、可辨认边界的按钮，以及三栏式组织；0.10.0 阅读页同时改成 44px 顶栏、偏小的裸文字工具、底部工具坞、三态札记切换和自动收栏。单个改动都有目的，但一起发生后，入口位置、按钮形态和正文比例都变了。

本次静态对照还发现：阅读时自动展开／收起页边栏会改变可用宽度；适宽比例随宽度变化，又会引发画布和文字层重建。用户感觉到的“卡”，可能同时包含性能延迟和版面跳动。**这是待验证的风险链路，不等同于已经确认了全部根因。** 之前合成文本文件的滚动帧率结果，不能替代用户实际文献与交互场景的体验。

## 2. 融合的总体方向

### 保留与回调

| 部分 | 设计决定 |
|---|---|
| 书府页面 | 保留现有组织、卷帙／题签、宽行距与详情栏；不再整体改版 |
| 品牌与色彩 | 沿用现有叶形标志、笺／Glossleaf、中英文衬线字体和六套全局配色 |
| 通用顶栏 | 回到书府的 60px 高度、字号及留白；品牌、主操作、书府／小传与设置使用相同位置规则 |
| 阅读工具 | 顶栏下方仅保留页码、原文／对读、缩放、札记与更多。高亮和批注随选区出现；撤销／重做等低频操作收进更多，不重复常驻 |
| 新能力 | 目录、缩略图、书签、一键颜色、下划线、引用格式、检索与自动保存均保留 |
| 自动收栏 | 默认关闭。只在用户主动进入专注阅读时隐藏工具，避免滚动中顶栏高度变化 |
| 札记入口 | 一次点击明确开关；笺注／札记使用同一侧栏的页签，不再用一个按钮暗含三次不同切换 |
| 朱批 | 保留淡化的朱批框与文楷；写作与回顾放在同一右侧区域的不同状态中，不再新增第三块会反复撑开的页边栏 |

### 页面之间如何联系

```text
书府
[叶形标志 笺] [搜索………………………………] [导入] [书府｜小传] [设置]
[卷帙／题签] [文献列表…………………………] [文献详情……………]

阅读
[叶形标志 笺] [‹ 书府  文献标题……………] [导出] [书府｜小传] [设置]
[3 / 13] [原文｜对读]          [缩放] [札记] [⋯]
[原版 PDF／正文…………………………………………] [笺注｜札记………]
```

导入仅在书府出现；阅读时相应主操作位置放导出。同一位置继续承载明确的页面动作，右侧主页切换和设置不漂移。标题只相对放大，保持单行，过长省略并提供完整名称提示。

从书府打开文献后保留列表筛选、已选文献和滚动位置；返回直接恢复。侧栏共用背景、边线、标题与页签规则，不能一页是按钮、一页又变成难辨认的裸文字。

## 3. 选区工具条与右键菜单：同一组件，两种展开状态

### 收起态

```text
┌───────────────────────────────────────────┐
│ ● ● ● ● │ U │ 批注 │ 复制 │ ⋯            │
└───────────────────────────────────────────┘
```

### 展开态

```text
┌───────────────────────────────────────────┐
│ ● ● ● ● │ U │ 批注 │ 复制 │ ⋯（选中）     │
├───────────────────────────────────────────┤
│ 翻译选区                              ⌘T │
│ 复制引文                                 │
│ 存为摘录                                 │
│ 粘贴为朱批                               │
├───────────────────────────────────────────┤
│ 识别修正…                              › │
└───────────────────────────────────────────┘
```

这是**一块连续的面板**：一条外边框、一层轻阴影、4px 圆角，内部靠淡分隔线分组。展开区与工具条相接，不另开一个大菜单，也不叠两层阴影。

- 左键选择文字：出现轻工具条。
- 点击“⋯”：同一面板展开低频操作。
- 有选区时右键：直接打开这同一面板的展开态；若面板已经显示，更新现有面板，不再创建第二块。
- 复制、高亮、下划线、批注只在顶部保留一份；展开区删除重复的“复制选中文字／高亮选中文字／批注选中文字”。
- 不保留占一整行的“已选原文”标题。需要字数时用 12px 次要文字，不再用难辨认的小角标。
- 整块面板重新测量避让，在选区上方或下方保留至少 8px。展开时整体避让，不能只把下拉区向下压到被选文字上。
- 上下都放不下时，使用已经预留的页面工具区域承载；不能为了浮层重新缩放 PDF。
- 菜单项按下时保留文字选区与锚点。点击空白、滚动或 Esc 收起；不弹“高亮已保存”。
- 无选区右键：展示页面相关操作，不能出现不可用的“复制选中文字”。
- 点到已有高亮／批注：显示该标注的编辑、颜色、删除操作，不能混入段落修正。
- “识别修正”属于低频纠错，置于最后的次级入口；常态不展开。

这部分保留截图中四个颜色点、U、朱色批注、复制和更多的轻巧感，主要改变的是**两种入口背后的结构与状态一致性**。

## 4. 字体、控件与间距

| 项目 | 拟用尺度与规则 |
|---|---|
| 通用顶栏 | 60px，与书府一致 |
| 阅读工具带 | 约 40px；分组之间 12–16px |
| 普通界面文字 | 14–15px，说明文字 12–13px，不把主操作压到 11–12px |
| 文献标题 | 中文约 17px，英文约 18px，适度字重，单行省略 |
| 按钮 | 32–36px 高，4px 圆角，淡边框与轻反馈；不做胶囊，也不全部去掉边界 |
| 图标 | 同一线性系统；视觉尺寸 16–18px，点击区域至少约 32px |
| 选中态 | 低饱和底色＋细线／边界，文字始终清楚；不能只靠难以察觉的色差 |
| 分组标题 | 保持透明，不给卷帙、题签重新加蒙版 |
| 右侧区域 | 与书府详情栏共用尺度，桌面默认约 324px，可按已有规则调整 |
| 正文纸张 | 保留原版 PDF；适宽上限以约 840px 的舒适阅读宽度为起点验证，不改变原文字体、不对正文重新排版 |

中文继续用宋体／衬线体系，朱批用文楷；英文继续用 Source Serif 4。控件字重以中等为主，文献标题稍重。颜色沿用项目已有主题，不为阅读页再配另一套不相干的颜色。

## 5. 朱批、侧栏和缩放：稳定优先

1. 默认阅读状态稳定，不因当前页有无朱批而自动增减一块 260px 栏位。标注通过明确的批注图标或轻色点提示，点击后打开统一侧栏。
2. 原文与笺注／札记之间是用户明确的开关；开始写朱批时，在同一侧栏进入编辑状态。保留清楚但淡化的文本框，不盖正文。
3. 若侧栏已经打开，编辑和回顾之间不改变正文宽度。关闭编辑仅回到札记列表，不自动把整页放大一次。
4. 页面空间足够时优先使用现有留白，保持当前 PDF 比例。手动缩放后，不因开关侧栏再自动“适宽”。
5. 需要新适宽比例时，布局稳定后只计算、绘制一次；保留旧画布直至新画布就绪，不一边拖动宽度、一边反复重建。
6. 窄窗口采用底部写作抽屉，保持正文宽度；定位到引用处后不持续追着光标自动滚动。恢复动画被用户主动滚动或翻页时立即取消。
7. 默认不动画化 PDF 的宽、高和倍率。过渡集中在按钮反馈、侧栏内容的短淡入；避免多块区域同时位移。
8. 图标、页码输入、上一页／下一页、返回书府等触发动作保留边界或明确悬停反馈；纯展示信息保持无按钮形态。

## 6. 卡顿排查：下一阶段的执行顺序

本轮只做静态检查与设计，不修改渲染器，也不以原型流畅度证明正式应用性能。

### 源码中已看到的风险

- `ReaderView.tsx` 的滚动处理遍历页面位置、更新阅读进度，并对段落位置排序；这些读取与全页状态更新发生在滚动链路中。
- 同一组件每次渲染都检查正文宽度；宽度又参与 `renderScale` 计算。边栏和适宽耦合时，可能触发额外布局与绘制。
- PDF 页面列表由父级直接生成，许多回调和数组在渲染时重建；需要确认普通滚动是否让没有变化的页面一起渲染。
- `MarginRail` 的布局订阅依赖每次构建的新数组；需要确认滚动过程中是否不断重装观察器、重新测量。
- 44px 顶栏通过 margin-top 自动收起，改变正文可用高度。即便平均帧率尚可，用户仍可能感到页面挪动和交互不稳。

### 实施顺序

**先测量**：用能复现问题的实际 PDF，分别记录滚动、选区、开关札记、写批注、缩放和书府／阅读切换的时序；区分文件解码、界面更新和版面跳动。保留当前版本可对照。

**再减工作量**：滚动按帧合并；只计算可见页附近的位置；不在滚动时反复排序全部段落；非必要进度更新移出整个阅读树；稳定回调、数组与页面组件，避免未变化页面重渲染。

**再断开重排链**：先移除“有批注就自动撑栏”和自动收顶栏。侧栏状态与 PDF 倍率分离；文字层和画布在明确的缩放／适宽操作后更新，避免多个测量入口互相触发。

**最后加过渡**：确认位置稳定后再加 120–180ms 的轻反馈。动效不能用来掩盖或加重卡顿。

### 验收口径

- 书府与阅读的顶栏品牌、主页切换和设置位置符合共同布局；中英文与 900／1280px 以上窗口逐项检查。
- 选区工具与右键展开态同时只出现一个面板，重复项为零；各方向避让不压住被选文字。
- 开关编辑状态不反复改变正文倍率，引用定位误差目标在 2 CSS px 内。
- 连续滚动时，不应触发所有页面的文字层或画布重建；同时统计帧时间与长任务，而非只看平均 fps。
- 常见按钮反馈以 100ms 内可见为目标；大型文件初次解码单独测量，不与按钮响应混为一项。
- 文本型中文 PDF、图表密集 PDF、扫描 PDF、密集批注、对读、触控板连续滚动，以及 50%／100%／200% 缩放分别验证。
- 阅读自动保存、引用／札记导出、书签、原件关联与中英文界面不能因样式回调而丢失。

## 7. 本轮原型范围与下一步边界

原型演示同一外壳下的书府／阅读、同一选区面板的收起／展开／右键入口、朱批编辑状态与语言适配。示例正文是界面示意，不是原论文内容；文件导入、模型翻译、剪贴板、保存与导出不连接真实数据。缩放按钮只演示控件状态，不用于检验真实 PDF 缩放质量或性能。

本轮**没有改动正式工程、数据库、API 设置、应用包或 latest 指向**。后续落地应在独立版本中先完成一页融合样式与真实文件性能复现，验证无跳动后再推广。不会直接覆盖 0.10.0，也不会以降回旧数据库格式实现视觉回调。

推荐方向：**采用这份融合稿的统一外壳与一体化选区菜单；保留新版能力，以更小的变更恢复熟悉感。**

## 8. 设计预览检查

已检查这份独立设计预览：统一面板只出现一份，快捷行与展开区直接相接；整块面板与示例选区保持约 8px 间距；朱批框不覆盖正文。书府／阅读切换时，顶栏高度、品牌位置、右上角操作区位置与右侧区域宽度一致。中文、英文、浅色、深色以及多种预览宽度均已查看。

聊天中的窄幅预览会换行适配，不由此增加移动端开发范围；正式应用仍按桌面窗口约束设计。以上是设计原型的排版检查，不是正式应用的性能验收。

## 9. 本次收简决定

删除界面中的“刊印”附加标签和独立页码体系，页码控件仅显示“当前页 / 总页数”，点击直接输入 PDF 页码。同步取消相对跳转语法，避免让普通翻页变成需要学习的工具。原论文印在纸上的页码属于原件内容，不擦除；引用需要的出版页码仍作为文献元数据处理。

常驻阅读工具带不再重复摆放选择、高亮、批注、撤销和重做五个按钮。文字相关动作随选区出现，保留用户认可的一体化工具条；撤销／重做和选择模式等低频项归入更多。每个动作只设一个主要入口，默认不展开右键菜单。上述修改限于设计预览和方案，正式应用尚未修改。
