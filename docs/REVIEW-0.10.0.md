# 笺 · Glossleaf 0.10.0 阅读页改版与操作审阅

2026-10-31。基于 0.9.5；依据《阅读页改版方案》完成三期内容。历史版本独立保留，新工程与交付放在 `versions/0.10.0/`。

## 阅读界面

常驻区域改为单条 44px 顶栏，标题相对放大，长标题省略并可悬停查看全名。右侧固定为原文/对读、Aa、札记、导出和更多五个入口。滚动时顶栏淡出，靠近顶部恢复；底部页码提示在停下 1.5 秒后收起。专注模式隐藏顶栏、工具坞、导航和侧栏，仅保留小页码与退出入口。

标注工具集中到底部工具坞，默认是一枚笔头；按 T 展开选择、高亮、下划线、页批、橡皮、撤销与重做。激活态使用细朱线，避免大面积底色和圆角按钮。选区工具是一行：四个一键颜色、下划线、批注、复制和更多。更多内提供引文、摘录、粘贴为批注和选区翻译。工具条与选区保持 8px 距离；没有上下空间时使用底部保留区。滚轮、点击空白或选区消失会收起它；排版调整不会误取消选择。

Aa 包含缩放、适宽、旋转、单页/连续、纸色、亮度、朱批字体和固定底部写批注。纸色及亮度只影响屏幕呈现，不修改原文件。全局的六套配色、品牌标志和书府/小传等宽侧栏沿用前版。

中文界面保持中文按钮与提示；英文界面继续适配 Glossleaf，使用英文阅读器的词汇与排版。文献原题、作者、模型标识以及 PDF、Markdown 等格式名称不作为界面翻译对象。

## 页码、目录与位置

- 页码常态为轻文字，点击后提供自动全选输入、上下键、相对跳转（+3/-2）、缩略图预览、批注刻度、目录/书签入口以及返回上次位置。
- 自动读取 PDF PageLabels，包括罗马数字及不连续页码。唯一的刊印标签优先匹配；普通有效数字也可作 PDF 序号。重复的非数字标签不会被随意猜测。
- 文档信息可手填“PDF 第 1 页对应的刊印起始页”，留空恢复原有标签。没有 PDF 标签时也可从已确认的书目起始页补充；不会假称从扫描图像识别了页码。
- 札记、复制引文与 Markdown 导出使用当前刊印映射，同时保留 PDF 序号定位。更新映射无需重写历史坐标。
- L 打开目录、缩略图和书签。目录来自 PDF 自带结构；缺失时明确提示，使用缩略图或手动书签。缩略图接近视窗时才绘制。
- 单页模式中的札记、搜索和批注跳转会先装载目标页，再定位。J/K 可以在朱批之间跳转。

## 朱批与札记

选中文字后按 Enter，或点击“批注”，直接在页边输入；N 为当前页写页批。宽窗口让出 260px 页边空间，输入框与正文分开；不足 1100px 或手动指定时改为约 40% 高度的底部抽屉。引用位置移到可见区上部；关闭时用约 200ms 过渡恢复原文锚点。系统启用减少动态效果时直接恢复。

朱批采用轻边线、朱色文楷、四种标记颜色和“？/！/★/◆”速记前缀。长笔记改用衬线字体，也可手动切换宋体或无衬线。文楷随应用离线提供，授权与版权说明随包保留。

停止输入 0.8 秒后自动保存；失焦或收起前也会保存。新建空批注不落库。现有批注清空时明确询问删除，避免误删。删除会等候已发起的保存完成，避免删除后复活；外部修订冲突保留输入供处理。高亮、朱批、摘录保持独立生命周期，可撤销与重做。文字朱批有轻高亮与细朱线，收起态为朱点；密集批注可逐条展开。页边只计算可见页及相邻页的位置。

顶栏“札记”按 **页边 → 总览 → 隐藏** 循环。总览用于回顾，提供按刊印页分组、文字搜索、颜色与前缀筛选、仅摘录/仅朱批、编辑、定位、复制和删除。编辑回到页边或底部写作区。导出合并到顶栏一个入口，支持仅札记或包含原文的 Markdown，以及现有五种引用格式与书目交换格式。

## 操作速查

| 目的 | 操作 |
|---|---|
| 写选区朱批 | 选择文字 → Enter |
| 写当前页页批 | N |
| 收起朱批并保存 | Esc 或 ⌘/Ctrl+Enter |
| 相邻朱批 | J / K |
| 工具坞 | T |
| 目录 / 缩略图 / 书签 | L |
| 本文查找 | ⌘/Ctrl+F |
| 专注模式 / 退出 | F；也可点击页码旁 F |
| 翻页 | ← / →、PgUp / PgDn，或页码浏览 |
| 撤销 / 重做 | ⌘/Ctrl+Z / ⇧+⌘/Ctrl+Z |
| 缩放与纸色 | Aa |
| 引文、札记和书目 | 导出 |

选区翻译进入右侧笺注，不在正文上扩展翻译浮层。搜索是左侧抽屉，与目录互斥；命中在原文轻色标记。更多内提供文档信息、原件打印、重载、快捷键和阅读设置。

## 原件与数据

本地 PDF 继续直接关联原路径，阅读、高亮和朱批不增加一份托管原件，也不改写原 PDF。文献名/DOI 检索经候选确认后，能公开获取的全文才下载为单份托管附件，重复下载不重复保存。完整备份是用户主动请求的独立副本，会包含能读取的关联文件；它与日常导入的存储方式不同。

本版数据库升级到 **schema 7**，增加下划线样式。首次升级会在事务前创建数据库快照，旧批注默认保持高亮；快照是数据库快照，不能代替包含附件的完整备份。**升级前请在“书府与备份”中创建完整备份。升级后的文库不能直接用 schema 6 的旧版打开；回退应恢复升级前备份到独立文库。** 本轮开发验证全部使用隔离测试书库，没有升级或改动用户真实书库。

阅读工具偏好、刊印映射与书签单独按文档版本保存，不覆盖段落编辑数据。高亮、页批和引文保留文档版本及 PDF 坐标、文本前后文锚点；不匹配的位置保留条目并提示，不静默删除。

## 当前边界与尚未验证的路径

1. “系统打印（原文件）”把原件交给系统阅读器，随后使用系统打印；没有把应用界面截图打印，也没有把应用批注嵌入原 PDF。
2. 批注可导出 Markdown/阅读数据，尚不支持写回标准 PDF 批注；Zotero 仍为导入，不是双向同步。
3. 扫描 PDF 可原版阅读与写页批，但没有 OCR，所以没有文本层的页面不能划词和全文检索。EPUB、CAJ 仍未实现应用内阅读。
4. 实验性夹注保持入口与复杂页面回退；它不是所有版式都适用的默认阅读模式。
5. 模型协议、选区流式翻译和元数据流程通过本地模拟服务验证。本轮没有使用真实付费 Key，也未验收各供应商账户权限、期刊登录与受限全文下载。默认模型 ID 可自行修改，实际可用模型取决于服务商与账户。
6. 阅读性能用合成的 200 页文本 PDF 和 200 条朱批测量，不能外推为所有扫描件、复杂图版或不同硬件的帧率保证。
7. 本次交付为 macOS Apple Silicon 本地签名预览，未公证；Windows、Linux、Intel Mac、外部打印机未验证。

最终测试数、原生回归、性能与打包校验以同目录 `evidence-0.10.0/verification.json` 为准。

## 最终验证

93 项数据与逻辑测试、10 组原生窗口回归通过；类型检查、生产构建、本地签名和打包英文冷启动通过。普通 PDF 在 DPR 1/2/3、0/90/180/270 度、50%/100%/200%/400% 缩放下的高亮坐标误差均小于 1 设备像素。宽/窄窗口编辑框均与原文分离；单页模式跨页札记定位已验证。

开启页边朱批的 200 页文本 PDF、200 条朱批测试：连续滚动 18,000px，记录 725 帧、12.10 秒，平均 **59.92fps**，帧间隔 P95 为 16.8ms。初始提取 2 页文字、绘制 1 个画布，滚动后保留 16 页文字、1 个活动画布。本机记录达到方案 50fps 目标；测试不代表扫描件、复杂图版或其他硬件的保证。

选区翻译经本机 SSE 服务流式返回；付费云服务调用为 0。隔离测试与打包均未读取用户 API Key 或修改真实书库。应用打包输出逐文件比对，共核对 211 个构建文件一致。
