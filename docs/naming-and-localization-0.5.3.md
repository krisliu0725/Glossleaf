# 笺 Jian 0.5.3 · 文学命名与中英文界面

交付日期：2026-10-30。基于 0.5.2 的独立工作副本。用户选择“文学体裁：文集 / 书页 / 小传”，本轮将这一方向落实到应用界面、英文文案、布局和开发交接中。

## 名称体系

中文从书籍、阅读与书写的词汇中取名，英文采用自然的书籍与写作词汇。这是产品语义设计，不将每个名称声称为严格的古代文体，也不复制 Claude 的具体名称。

| 功能 | 中文 | English | 产品含义与边界 |
|---|---|---|---|
| 文献管理主入口 | 文集 | Anthology | 汇集文献，操作说明继续使用“文献” |
| 阅读主入口 | 书页 | Leaf | 翻开原文，承载阅读、双语和行间模式 |
| 个人与数据主入口 | 小传 | Memoir | 阅读经历与使用情况的个人回顾 |
| 数据总览 | 卷首 | Preface | 打开个人回顾的第一页，先看核心指标 |
| 阅读记录 | 日课 | Journal | 日常阅读的连续记录 |
| 话题与领域 | 志趣 | Themes | 研究兴趣与已确认的分类 |
| 模型用量 | 用度 | Ledger | 请求、Token 和缺失用量的记录 |
| 保存的阅读摘录 | 札记 | Marginalia | 阅读中留下的摘录与评论 |
| 译文面板 | 译注 | Translation | 英文采用清楚的功能名，避免误导为只有词义注释 |
| 术语管理 | 词林 · 术语表 | Lexicon | 中文标题保留“术语表”解释用途 |
| 文献集合 | 卷帙 | Collections | 中文分组有书籍气质，管理动作保持明确 |
| 文献标签 | 题签 | Tags | 标签作为分类线索，保留跨软件理解 |
| 设置入口 | 文房 | Settings | 中文有书写空间的意味，英文保留易识别的名称 |

主导航带有功能解释提示。导入、搜索、复制、保存、取消等动作仍使用明确词汇；例如“存为摘录 / Save excerpt”，不因文学风格变成难猜的隐喻。英文主名称只在必要位置出现，不在每个按钮中堆叠双语。

## 英文版的实际适配

同一应用提供中英文界面。主界面、阅读器和设置内均可切换，偏好保存并在重新启动后恢复。旧版本仅保存在 localStorage 的选择，在可读取时迁移至主进程偏好文件。不改变文库 schema。

适配范围包含文集列表与详情、搜索范围、索引管理、DOI 表单、引用与导出、阅读模式、选区操作、翻译配置、术语、后台任务、个人资料、Dashboard 各分页、统计口径、外观与数据设置，以及应用生成的常见状态、错误和导入说明。

英文按完整场景重写：

- “访问页可提取字数”在指标卡中用 **Text coverage**，数值标为 characters；说明区分文字覆盖与实际逐字阅读。
- “用度”采用 **Ledger**，明细直接写 Input tokens / Output tokens / Unreported requests。没有用量回传时保持未知，没有账单接口时显示 Billing data unavailable。
- 常用按钮缩短，详细统计口径在 Method 提示与说明弹窗中完整保留。
- 数量处理单复数，日期采用英文界面的 en-US 格式。时区仍是用户所在时区，不因界面语言变成美国时区。
- 英文使用 K 等数字缩写、sec / min / hr 时长单位、英文月份和星期；中文保留“万”、中文日期和时长。
- 作者表单使用 Family name / Given name / Organization。DOI、CSL-JSON、BibTeX 和模型 ID 保持标准写法。
- Markdown 阅读成果导出的标题、页码、来源、评论等结构文字随界面语言适配。引用格式仍明确标示 GB/T 7714-2015 numeric，不因切换英文擅自改成另一种规范。

切换界面语言不会改写文献题名、作者、PDF 文字、笔记、摘录、术语内容或已有译文，也不会改变翻译目标语言、API 地址、模型 ID、Key 与授权选择。外部服务原样返回的未知错误详情和机器标识保留原样，避免编造含义。系统文件面板原生按钮的语言由 macOS 控制，应用提供的标题与类型说明已接入语言设置。

## 视觉与交互

保留纸白、墨色、细线和克制的朱色点缀。主要变化是排版与层级，不增加装饰性大卡片、渐变光晕或背景插图。

中文标题沿用宋体方向，英文标题使用系统可用的 Iowan Old Style / Baskerville / Georgia 衬线栈；界面控件保持清楚的无衬线字体。通过系统栈调用字体，没有抽取、复制或打包系统字体，也没有新增外部字体依赖。

英文标题调整字距和行高，按钮与导航取消中文式大字距。长表单增加可用宽度，作者角色、下拉框、隐私说明和固定页脚分别适配。阅读器工具栏允许按宽度换行，窄窗口隐藏文献标题，保留返回、页码、模式和常用操作。行间模式采用简短 Tr. 标记，完整英文含义通过可访问名称提供。

文集中栏继续保持上一版压缩后的 **89 CSS px** 常驻高度。搜索范围留在搜索框右端，低频操作在更多菜单，索引状态在底部。移除了旧 Dashboard 标题旁重复的语言入口，统一使用全局工具栏与设置。

本轮修正：切换语言后缓存的文集标题不更新、星期标签遗漏、服务下拉框遗漏、过长统计标题，以及已保存状态提示的语言切换。弹窗继续隔离背景、限制焦点并恢复触发按钮焦点。

## 验证与截图

所有截图、阅读和 Token 验证均使用隔离合成数据，不是用户真实记录，没有调用真实付费模型 API。

通过严格类型检查、生产构建、49 项自动测试。新增测试覆盖词条插值完整性、单复数、已保存状态切换语言、结构化校验错误，以及英文导出保留中文内容。

英文全流程检查覆盖文集、设置、服务配置、元数据、小传分页、分类、阅读器、整篇任务确认、术语、文内查找及行间界面；应用自有文案出现中文残留时会使检查失败。语言选择项保留“中文”，数据截图中的中文文献与话题属于内容，不应自动翻译。

英文 Dashboard 使用合成的 **13,080,000 ms 阅读记录、44,812 个已回传 Token、10 次未回传请求**，检查 1280、900、760 宽度及明暗主题，没有页面水平溢出。760 是额外压力检查，正常最小窗口宽度仍为 900。

文集实测：1280 窗口中顶部 89 CSS px、列表高度 611 CSS px；900 窗口中顶部仍为 89 CSS px、列表高度 548 CSS px。菜单、搜索范围、清空搜索、索引弹窗与焦点恢复通过。行间回归验证原文像素重组差异为 0、滚动锚点变化为 0，标注、链接和缩放通过。

完整结果、冷启动偏好检查和预览应用启动检查记录在 **docs/evidence-0.5.3/**。截图均注明为合成材料。

## 开发维护

| 位置 | 职责 |
|---|---|
| src/renderer/src/i18n.ts | 导航与结构文案、语言订阅、本地用户名 |
| src/shared/ui-en.json | 应用自有界面的英文词库 |
| src/shared/localization.ts | 插值、数量、状态与结构化错误本地化 |
| src/renderer/src/LanguageSwitch.tsx | 统一语言切换 |
| src/renderer/src/design/localized.css | 语言排版与英文布局 |
| src/main/preferences.ts | 与主题共存的语言偏好、原生弹窗 |
| src/main/m4/exports.ts | 导出结构文字适配，保留内容与引用标准 |
| tests/localization.test.ts、scripts/i18n-*.cjs | 本轮自动与桌面验证 |

只允许把应用拥有的文案交给本地化函数。不要遍历 DOM 替换中文，不要把标题、PDF 文本、笔记或模型译文送入界面词库。新增功能应同时提供中英文文案、完整语境和窄窗口检查。状态优先保留稳定来源词条，避免拼接半句。

API 继续允许自行填写 DeepSeek、Google Gemini API / Gemma 4 或自定义服务的基础地址、协议、模型 ID、Key、目标语言、Temperature 与超时。示例模型不承诺当前服务商权限或可用性，实际以服务商开放和用户连接测试为准。

## 交付边界

这是本地开发预览。macOS arm64 应用采用 ad-hoc 签名，未做正式 Developer ID 签名和公证。正式发行、真实长时间阅读、大文库性能、完整恢复矩阵和原有 M2 历史边界仍需后续验收。M6 行间模式继续标为实验，复杂页面保留原版。

历史设计文件作为阶段档案保留。发生命名或语言范围冲突时，以本文件与当前实现为准；历史文档曾写的“完整英文待办”不代表本轮界面状态。
