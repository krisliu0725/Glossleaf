# 笺 · Glossleaf 0.9.4 全应用审阅与操作说明

日期：2026-10-30。基线：0.9.3。审阅对象为本地桌面源码、独立数据服务与隔离的原生窗口。真实文库、API 密钥和原始项目均未修改。

## 本轮结果

批注现在占用独立空间：窗口宽度不小于 1100 时使用右侧页边笺，更窄时使用底部短笺。不会盖在 PDF 正文上。打开时暂时让出译文侧栏的位置，关闭后恢复原先页签与滚动；批注仍绑定原文位置。淡纸底、细朱线、较短的输入框和清楚的收起按钮，保留可编辑的框而降低装饰感。原文件不会被改写。

页码控件合并为轻薄的“当前页 / 总页数”，取消数字微调箭头，扩大数字与分隔线间距。输入页码后按 Return 或移开焦点再跳转，Escape 放弃输入；输入 `13` 时不会在输入 `1` 后先跳走。上一页、下一页继续放在阅读工具条中。

书府 Library 与小传 Memoir 共用 216px 侧栏，中文、英文和 900/1280 窗口均一致。主页面进入、设置分区、札记及主要控件加入约 140–180ms 的轻淡入和状态过渡；没有对 PDF 坐标层做缩放动画。系统选择减少动态效果时关闭这些动画。

新增六套应用全局配色，入口为 **文房 → 通用 → 纸色与墨韵**。全局纸色、文字、线条、选中状态与图表随配色变化；品牌标识配色、高亮色谱分别管理，历史高亮保留原色，原版 PDF 保持原色。每套都有日间与夜读版本，主题仍支持跟随系统。

## 整理后的操作逻辑

| 入口与目的 | 实际操作 | 保存结果与边界 |
|---|---|---|
| 已有本地 PDF | 书府 → 导入 → 关联本地文件；也可拖入 | 关联原件，日常不额外复制附件；移走原件后需重新定位 |
| 从 Zotero 迁入 | 导入 → 从 Zotero 导入 → 检查来源 → 确认导入 | 元数据、集合、题签与可映射批注导入本机；附件关联原路径；属于导入，不是双向同步 |
| 只有题名、文件名或 DOI | 导入 → 通过题名或 DOI 查找 → 核对候选 → 确认入库 | 尝试获取可用全文；未获得全文也保留文献条目，可重试或关联本地 PDF |
| 修正文献信息 | 选中文献 → 更多 → 编辑信息与检索元数据 | 对照候选，勾选字段后保存；不会把文件名推断的作者当作已确认作者 |
| 阅读与标记 | 阅读 → 选择文字；高亮 / 批注 / 复制 / 翻译 | 高亮保留选区，朱批单独保存；右键菜单随选区和原文/译文上下文变化 |
| 写一条短批 | 选区工具条 → 批注；或 N 后在原文落点 | 600ms 停笔自动保存；空白草稿不生成条目；已有批注清空时需明确删除 |
| 查找与定位 | 阅读选项 → 查找；或书府检索正文、文献信息、撷英 | 可跳至文档页和匹配位置；正文搜索依赖索引与可提取文字 |
| 翻译 | 文房 → 翻译 → 选服务、端点、模型及密钥 → 测试 → 阅读时翻译 | 选区、本页和全文任务分别处理；页面用量、Token 只记录服务实际返回字段 |
| 引用与导出 | 书府或阅读工具条 → 引用与导出 | GB/T 7714、APA 7、MLA 9、Chicago Author–Date、IEEE；书目与阅读成果有各自格式 |
| 查看自己的阅读 | 小传 → 日课 / 志趣 / 用度 | 分别查看阅读行为、话题领域、模型调用；统计基于记录，未知值不补成零 |
| 原件移动后修复 | 附件旁“重新定位原文件” | 内容指纹相同才恢复同一版本；内容改变应重新导入新版本 |
| 迁移与恢复 | 文房 → 书府与备份 → 立即备份 / 恢复 | 明确创建完整备份时才把关联原件收进备份；恢复前应备份当前书府 |

## 审阅中发现并修复的问题

1. 居中的批注框遮住正文；现改为独立右侧或底部区域，编辑与阅读互不覆盖。
2. 页码即时跳转使多位数输入不稳定；现改为完成输入后提交，并支持取消。
3. 两个主页分别使用不同的宽度来源；现统一为共享布局变量。
4. 关闭批注时可能丢失译文滚动位置；现保存并恢复先前位置与页签。
5. 英文界面的批注保存状态仍出现中文；已补充自然的英文提示。
6. EPUB 等附件会误入 PDF 阅读器；现仅选择可读 PDF，其他格式显示“仅保存附件”，界面和底层调用均阻止错误打开。含多种附件的文献会优先打开 PDF，并仍可定位原文件。

7. 撤销后立即删除同一批注时可能使用过时版本；现在操作队列会核对自身历史产生的最新版本。删除等待在途保存完成后执行，成功后才收起编辑框；失败时保留内容与错误提示。

## 当前尚未实现或仍有限制

这些项目不能当作已经完成的功能：

| 优先级 | 项目 | 当前真实状态 | 可用的替代路径 / 后续工作 |
|---|---|---|---|
| 高 | 扫描件 OCR | 没有 OCR。扫描 PDF 可看原页、落点写批注；不能凭图片生成可搜索文字或做文本翻译 | 先对原件 OCR 后作为新版本导入；后续增加本地 OCR 和对应坐标验证 |
| 高 | 任意文章自动下载 | 只尝试可获取的 PDF 来源。付费墙、登录下载、服务器拒绝、无可用地址都可能失败 | 保留条目，用户自行取得 PDF 后关联；不绕过出版社限制 |
| 高 | 任意文章作者自动匹配 | DOI 与题名检索已有流程，但没有覆盖所有中文数据库或保证正确的全自动识别 | 逐字段核对候选；无 DOI / 异常题名时手工修正作者、期刊、年份 |
| 中 | EPUB / CAJ 内置阅读 | 可保存关联附件；当前阅读器只支持 PDF。已阻止错误进入 PDF 阅读器 | 通过访达定位原件，用相应软件阅读；后续独立实现格式支持 |
| 中 | PDF 内嵌批注与带批注 PDF 导出 | 高亮、朱批保存在应用数据中。可导出 Markdown / 结构化阅读成果，不会回写原件 | 后续实现标准 PDF annotation 写出及与 Acrobat / Zotero 往返验证 |
| 中 | Zotero 双向同步 | 已有检查与导入、重复导入识别；没有实时双向同步或冲突合并 | 保持一次迁入或手动再导入；不能期待在一端编辑自动同步到另一端 |
| 中 | 长期撤销记录 | 撤销 / 重做作用于当前阅读会话；重开应用后不保留完整操作栈 | 数据仍保存，重要条目可借助备份恢复；持久化历史需单独设计 |
| 中 | 夹注稳定性 | 仍是实验功能。多栏、公式、复杂图表等页面会回退原版 | 日常使用原文或对读；复杂页面不承诺行间重排 |
| 中 | 多设备与协作 | 本机软件，没有云端账户、多人同时编辑与跨设备同步 | 使用明确的完整备份迁移，避免两个旧/新应用同时写入同一文库 |

## 已有实现，但本轮未完成真实外部环境验收

- **真实模型服务端到端**：DeepSeek、OpenAI、Claude、Gemini / Gemma、Kimi、Ollama 和自定义端点的配置、协议与模拟响应已验证；本轮没有调用你的真实密钥、没有产生付费模型请求。预设模型 ID 只作初始配置，仍应使用账号实际返回的模型列表并完成连接测试。不能将模拟通过等同于所有账号当前均能调用这些默认模型。
- **真实出版社与大规模中文文献命中率**：本轮用固定响应验证 DOI 解析、候选匹配、下载失败、取消和去重；没有重新访问真实出版社或统计中文文献识别成功率。
- **大体量真实文库与长时间内存占用**：已有批注 500 条性能场景与多种合成 PDF；没有对数万篇真实文献、数百页扫描件或连续数小时运行做压测。避免原件复制不等于零缓存、零内存占用。
- **Windows / Linux、Intel Mac、正式分发**：本轮原生验证为当前 Apple Silicon macOS。DPR 1/2/3 为设备参数模拟；不是三台物理屏幕。预览应用为本地签名，没有 Developer ID 公证或商店分发验证。

## 验证口径

验证使用隔离临时文库、合成 PDF / Zotero 来源、合成阅读与模型用量记录。模型和出版社响应使用本地或固定测试响应。正常用户文库不被注入演示数据。

新专项验证六套配色的 12 种昼夜组合、重启持久化、未知配色拒绝、中英文侧栏等宽、两个宽度的批注布局无相交、自动保存、13 页文献页码输入与取消、EPUB 入口保护以及减少动态效果。主要文字、辅助文字与强调色在各自三种应用纸面上的对比度均不低于 4.5:1；原版 PDF 和用户保存的高亮色不受该配色审计替代。
