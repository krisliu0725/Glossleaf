# M5 交互与视觉审阅

日期：2026-10-29。范围：文库、通用弹窗、DOI 元数据、引用导出、API 设置、本文查找及 Zotero 导入。新增 Dashboard 与后台统计另见 `M5-M6与Dashboard-验收说明.md`。

## 修复的真实交互冲突

| 问题 | 本次处理 |
| --- | --- |
| 弹窗仅覆盖视觉，背景仍能获得焦点；阅读器与文库快捷键可能抢走焦点 | 通用 Dialog 挂载至 body，将背景设为 inert。仅栈顶弹窗响应 Escape/Tab，关闭恢复打开前焦点。弹窗内查找快捷键不再触发底层页面切换。 |
| Zotero 导入使用独立弹窗，没有统一焦点处理 | 接入通用 Dialog，保留检测、导入、报告和告警内容；实际写入期间不可关闭。 |
| 连续输入时旧查询和旧分页可能覆盖新查询 | 文库、本文查找使用请求代次，输入立即清除旧结果；迟到响应丢弃，分页在加载时禁重复触发。 |
| 新集合 Enter 后失焦，再执行一次创建 | 改为显式表单提交与取消，移除失焦自动创建，增加同步提交锁。 |
| 导入期间再次拖入文件，可触发并发操作 | 导入和备份共享操作锁，弹窗打开时拖放不再触发文库导入。 |
| 导出复选框覆盖标题且平时不可见；Space 冒泡误选文献 | 固定独立勾选位置，16 px 原生复选框保持可见；只有行本身接收 Enter/Space 激活。增加已选数量与清空选择。 |
| 切换条目后旧详情仍可短暂操作；首附件不支持阅读导致按钮错误禁用 | 清除旧详情并校验详情 ID；阅读按钮查找任意存在活动版本的附件，无可读附件时提供原因。 |
| 引用预览失败后仍显示“正在生成预览…” | 分离加载与失败状态，显示错误及重试提示，失败时保存按钮禁用。复制引用与保存期间防止重复操作。 |
| 相同 DOI 已存在仍可直接点“确认入库”再得到错误 | 展示重复原因，明确勾选保留独立条目前禁用确认。 |
| 未授权发送内容时测试按钮可点，只在请求后报告错误 | 未授权时禁用测试并提供说明。保存配置仍可独立完成。 |
| 窄窗口或系统放大后详情栏挤压列表 | 小于 800 CSS px 时用“查看详情 / 返回文献列表”切换详情层；表单、工具栏可换行且不扩大视口。 |

## 视觉决策

延续纸墨配色、宋体标题与无衬线正文。使用细边线、留白和数字对齐区分信息；主操作使用实色，其余操作保持轻量，不增加装饰渐变或大面积阴影。

- 通用按钮高度 34 px；紧凑按钮 30 px。正文操作不再压缩到 24 px。
- 文库行以 5 px 小圆角和左侧标记表示当前条目，不为每条文献增加厚重卡片框。
- 统一 `.card`、`.card__label`、`.card__value` 和卡片圆角变量，供汇总面板复用。
- 禁用、按下、悬停与键盘焦点分别可辨认；深色搜索命中使用对应语义色。
- 对话框保留固定标题和底部操作区，内容单独滚动；短窗口仍可访问保存按钮。
- API Key、模型 ID、请求地址继续用清晰的表单显示，高级字段折叠。

## 验证入口

`scripts/m5-ui-e2e.cjs` 使用临时应用数据目录、临时文库和合成 PDF，Zotero 检测被替换为受控响应，不读取个人文库。专项覆盖：

1. 背景 inert、焦点留在弹窗、查找快捷键隔离、Escape 关闭与焦点恢复。
2. 集合 Enter 提交后再失焦只创建一次。
3. 复选框 Space 勾选不改变另一条文献的当前状态。
4. 故意延迟旧查询，验证迟到响应不能覆盖新查询。
5. 注入导出预览失败，验证错误展示与保存禁用。
6. Zotero 阻塞状态沿用统一弹窗行为。
7. 实际浅色、深色、窄屏详情界面截图及边界检查。

验证结果由运行产生的 evidence.json 记录；编译检查与原 M3/M4 流程需在整合构建后共同执行。

## 边界

本次属于应用内交互、外观与发布候选质量改进。正式签名、 notarization、公证、系统安装和真实大文库性能测试不属于已验收事项。视觉截图及脚本不能代替键盘使用、长标题数据和真实论文的持续人工检查。
