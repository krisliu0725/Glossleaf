# 笺 · Glossleaf 0.8.0 改进与交付说明

日期：2026-10-30。基于 0.7.0 独立副本实现；原项目和用户真实文库未改动。

## 本轮改进

| 用户需求 | 实际行为 |
|---|---|
| 看清左侧当前选择 | 统一淡青底、细轮廓、左侧青色标记、文字加重和图标着色；集合、题签、全部/最近等只保留一个当前入口，深色模式适配 |
| 本地文件避免重复保存 | 普通导入、拖入和 Zotero 附件均关联原件，读取原位置；本轮合成资料实测没有新增 blobs 附件副本 |
| 题名/文件名入库后下载 | 新增“按题名或 DOI 查找”；核对候选后保存记录，默认自动下载可获取的全文；下载附件只保存一份，显示可读文件名及来源 |
| 重新设计主题区 | 原创折角信纸与叶片线稿，中文“笺 + Glossleaf”组合，英文 Glossleaf 字标；900/1280 宽度及深色界面无头部溢出 |
| 原件移动与内容变化 | 同内容重定位保留阅读和批注；内容变化后重新导入形成新版本，防止旧批注错配 |
| 备份与后台工作 | 完整备份显式收进原件；日常文库仍关联。下载、索引、翻译与数据操作未结束时阻止恢复，恢复期间阻止新操作 |

## 现在怎么使用

已有本地文件：选择 **导入 → 关联本地文件**，或拖入文件。附件显示“原文件关联”。原件移动后，点附件右侧的重新定位图标，选择同一内容的文件。不要删除仍需阅读的原件。

只有题名、文件名或 DOI：选择 **导入 → 按题名或 DOI 查找**，核对候选作者、年份和出版物后入库，默认勾选自动下载全文。也可在无附件文献的菜单里选择“查找并下载全文”或“关联本地附件”。题名相似度只用于排序，不会直接认定作者或静默选中第一篇。

没有直链、下载超时、取消或出版社拒绝访问时，文献记录照常保留，失败的临时文件会清理。下载已有附件的记录不会重复联网或重复保存。

## 空间与升级说明

省去的是日常附件的重复副本。应用仍需保存条目、批注、全文索引、设置和译文缓存；不能据此承诺内存或磁盘完全不增长。文件核验与网络下载采用流式处理。

显式完整备份会在备份包内另存原件，这是为了让恢复不依赖旧电脑路径；不会让当前文库改为托管。恢复备份后的附件来自备份包，属于文库文件。原件缺失或已改动时完整备份会报错并清理半成品。

旧版已经保存的文库副本不会自动删除。此次没有对用户真实资料做清理或迁移；用户启动新版时自动升级至 schema 5，并在升级前保存元数据快照。升级前退出旧版；不要再用 0.7.0 打开已升级文库。快照不包含 PDF，不能代替完整备份。

## 全文获取依据与边界

按确认 DOI 查询 [OpenAlex 的开放获取位置](https://help.openalex.org/data/locations/)，再使用同 DOI 的 [Crossref 出版方全文链接](https://www.crossref.org/documentation/retrieve-metadata/text-and-data-mining/)。下载只接受公开 HTTPS，限制大小、时长和跳转，检查返回是否为完整 PDF；不绕过登录或付费访问。

真实公开检查中，示例 DOI 10.21105/joss.00861 成功下载 294,478 字节 PDF；另一示例 10.7717/peerj.4375 找到直链但出版方返回 HTTP 403，应用正确保留记录并报告未完成。测试未使用用户文献或付费模型。网络状态与出版方策略会影响后续结果，详情见随包证据。

此前引用样式、元数据候选、可配置模型、双主页与中英文字体仍保留，详见 [0.7.0 改进说明](IMPROVEMENTS-0.7.0.md)。工程接续见 [开发交接](../HANDOFF.md)。

## 验收结果

77 项测试全部通过，类型检查与生产构建通过。五组桌面回归通过，覆盖原件关联、Zotero 附件、重定位、自动下载/取消、恢复互斥、中英文品牌、选中态、引用/元数据、阅读及实验夹注。窗口缩小回归还修正了阅读器偶发未更新 PDF 适配宽度的问题。打包构建逐文件一致，ad-hoc 签名验证和英文冷启动通过；未进行正式签名与公证。
