# 笺 · Glossleaf 0.9.1 · 阅读舒适度与交互整理

2026-10-30。根据本轮十二条反馈，在 0.9.0 独立副本中实施。原项目、旧交付包和真实文库保持原状。数据库仍为 schema 6，本次不新增迁移。

## 顶栏与整体密度

- 品牌图形以 22px 显示，与字标间距为 12px；中文宋体字标与英文 Glossleaf 分别适配。保留 Logo V3 原始路径，本轮按用户新反馈调整显示尺寸与留白。
- 两个主页共用 HomeActions，右侧固定为“导入 → 书府 / 小传 → 设置”。小传也提供真实导入入口，切换主页时三个区域不移动。
- 主顶栏收敛到 60px；默认宽松列表最小 86px，紧凑列表仍可选择，最小 68px。标题、元数据、导航行距和字重一起增加，长标题继续两行显示。
- 阅读器论文标题仅从原先偏小的尺寸略微放大，采用 17px（窄窗口 16px）、600 字重的衬线字体；中文回落系统宋体，英文使用随包 Source Serif 4。未打包没有嵌入授权的小标宋字体。新安装的译文字号默认 17px，已有明确保存的字号继续尊重，可在设置调整。
- 查找收进阅读器三点菜单，⌘F 保留。macOS 红黄绿窗口按钮回到独立的原生标题栏，位于应用内容外；应用自己的顶栏从左侧 24px 开始，不再容纳系统按钮或保留大片空位。全屏交由系统管理。

## 题签与可见状态

题签默认只显示至少关联两篇文献的项目。展开、数量筛选和名称筛选全部在题签标题附近；可改为至少 3 / 5 篇或显示全部。低频题签仍保存在文献中，本轮不删除用户或 Zotero 的标签。

滚动条统一为细线、透明轨道，保留稳定占位，避免滚动时布局跳动。选中入口的浅墨背景与侧栏底色保持差异。按钮、菜单、分段开关、标签页、颜色槽统一悬停、按下、选中、展开和键盘焦点反馈；禁用态保持可辨。

## 原文与批注

原文选区采用带透明度的浅色，文本层选区文字保持透明，让下方 PDF 原始字形清楚显示。保存后的高亮仅在绘制时合并同一行相邻碎片，不跨栏、不跨行，也不改写原来的精确锚点。保存高亮不再显示“高亮已保存”。

朱批由方框“批”字改成低对比的细笔触，悬停或键盘聚焦时才增强背景；相邻聚合、编辑、自动保存、搜索与撤销重做保留。编辑浮层去掉醒目的朱色顶边，使用轻边界和更宽松的正文空间。

## 右键与右栏

原文选区菜单提供复制、高亮、批注、翻译；空白页面菜单提供原位置添加朱批、适合宽度和查找。译文菜单提供复制、编辑、重新翻译及批注对应原文。段落合并、忽略等功能放进“段落识别修正”，不再使用上一次激活的段落来猜测本次右键对象。

复制走具名的应用剪贴板接口，避免全屏切换后浏览器剪贴板权限导致按钮失效。主进程验证调用来源与文本长度，只暴露写入文本，不暴露任意 IPC 或剪贴板读取。

右侧译文与札记采用轻微纸面层次、柔和选中底色和清楚边界。译文操作放在卡片内部，不悬浮遮挡段落；正文按设置字号与 1.8 倍行距显示。保留全页/段落翻译和当前模型状态。

## 自然缩放

适合宽度按当前阅读窗格的真实宽度计算，大窗口不再停留在过小的固定纸张。缩放围绕当前阅读点或手势位置，水平与垂直位置一起补偿；触控板事件逐帧合并。新图像在离屏画布绘制好之后再替换，绘制期间保留上一帧，减少白屏和闪烁。单页渲染缓冲按像素预算限制；屏幕外页面继续释放图像。

产品处理参考了 Preview 的缩放与适配入口，以及 Zotero 对选区批注、来源与阅读器操作的区分，具体取舍以本轮反馈为准。[Apple Preview](https://support.apple.com/en-nz/guide/preview/prvw11470/mac)、[Zotero 阅读器文档](https://www.zotero.org/support/pdf_reader)。

## 验收与交付

最终结果见 evidence-0.9.1/verification.json。包含真实 macOS 窗口的中英文 900/1280 布局比较、原生标题栏边界与真实全屏进出、题签筛选、原生复制、右键操作、静默高亮、页边笔触、适宽/连续缩放及原有批注、引用、文件读取回归。截图使用隔离合成资料，译文为本地模拟响应，不代表真实模型翻译质量。

源码包包含本轮源文件、构建、文档、原始设计规范、Logo 资源、测试和校验信息。macOS arm64 应用为本地 ad-hoc 签名预览，尚未正式签名与公证。未调用付费模型，未修改原 PDF。

## 最新视觉修订

按本轮后续反馈，撤回过大的 76px 顶栏与 20px 以上阅读标题。最终采用 60px 应用顶栏、17px 阅读标题、22px 中文字标 / 20px 英文字标和更轻的字重。系统窗口按钮属于独立原生框架，不放在应用内。正文舒适度、题签筛选、轻量批注与缩放改进保留。

## 最终验收结果

86 项数据与单元测试、类型检查与生产构建通过；九组原生桌面回归全部通过。覆盖独立原生标题栏、真实全屏进出、中英文 900/1280 宽度、两个主页按钮位置一致、题签数量/名称筛选、复制、静默高亮、轻量朱批、缩放与手势焦点。原有批注、引用、原件关联、中文 PDF 和实验夹注均完成回归。三种 DPR 为 Chromium 设备参数模拟；并非三台物理显示器。

打包应用的构建逐文件比对一致，ad-hoc 签名验证与隔离英文冷启动通过。原 PDF 哈希保持不变，没有调用付费模型。合成材料和模拟译文只用于检查交互；具体数值见 evidence-0.9.1/verification.json。
