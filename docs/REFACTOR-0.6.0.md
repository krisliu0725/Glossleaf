# 笺 Jian 0.6.0 · 页面设计与功能重构交付

日期：2026-10-30。基于已交付的 0.5.3 独立工程副本，按用户提供的 JIAN_UI_REDESIGN_v2.md 实装。用户原工程、原压缩包和日常文库均未改写。

这次交付包含可运行的页面、连接真实本地数据的功能、英文界面、桌面验收和开发源码。配套品牌包已接入颜色 token、线性 SVG 与预览应用图标；字体按最新方案采用系统字体，没有附带字体文件。

## 一、已确定的产品取舍

1. 用户已确认：小传是独立的阅读数据 Dashboard，入口放在书府侧栏底部。展笺是阅读器，通过阅读按钮、附件行或双击文献打开，不把它们误改成封面/作者视图。
2. 书府列表的“视图”提供真实的紧凑/宽松两种密度；“排序”提供日期、标题、作者，不新增空壳页面。
3. 中文统一为书府、展笺、对读、笺注、札记、撷英、释名、卷帙、题签、文房。英文对应 Library、Reader、Parallel、Gloss、Notes、Excerpts、Glossary、Collections、Tags、Settings。
4. 危险操作与动作继续使用直接文案。阅读、导入 PDF、复制引用、移入回收站、恢复备份不改成难猜的隐喻。
5. 回收站采用手动恢复、持续保留的方式。本次没有增加按天自动永久删除，避免在本地阅读应用中引入隐式数据丢失。
6. 自动翻译默认关闭。模型地址、协议、模型 ID、Key、目标语言、Temperature、超时与补充提示词继续允许自行调整。

## 二、展笺：从卡片堆叠改为阅读流

### 页面与工具

顶栏保留六组功能：返回书府、页码、原文/对读、查找、侧栏、阅读选项。文献标题是静态文字，不计入操作组。界面语言移到文房；缩放、全文翻译和设置入口在阅读选项中；夹注只有在文房开启实验开关后才出现。

原文模式默认收起右栏，PDF 在可用内容区居中。对读默认 55:45，分隔条可拖动，也可用方向键调整，比例保存。PDF 以适应栏宽的基准乘以用户缩放，900 px 窗口中仍可使用双栏，主动放大时允许平移查看原页。

右栏为“笺注 / 札记 / 撷英”。模型只在栏底一行显示，点击进入翻译设置。术语管理位于文房 › 翻译；命中的译文术语带青色点线和原词提示。侧栏默认跟随原文，取消跟随开关。

翻译本页、停止、重试合并为状态动作。已译完的页面不再保留翻译按钮占位；失败以图标、文字和重试呈现。全文翻译放到阅读选项，保留发送范围与估算确认。

### 段落、过滤与对应

提取流程按行聚类，再结合行距、缩进、字号与栏位判断段界。支持标题、摘要、关键词、小节、正文、题注、脚注、参考文献和忽略块。

- 中文抽取空格及软换行会规范化，英文连字符断行按启发式连接。
- DOI、基金/作者简介等明确标记，以及页边噪声不会进入默认翻译列表。
- 相近页边位置在至少三页重复的文字会被识别为噪声。
- 作者行使用已知元数据与首页摘要之前的版面线索保守过滤。
- 跨页/跨栏连续正文在明确的续接信号下合为同一逻辑段落，各页坐标分别保留。原 PDF 不重排、不覆盖。
- 参考文献默认不自动翻译，脚注折叠。忽略内容可以从阅读选项或文房 › 高级与诊断中展开查看。

右栏不重复原文，不显示系统段号。未译块为虚线占位，悬停或键盘进入时提供翻译动作；已译块悬停/聚焦时出现复制、重译、保存摘录三个动作。译文正文默认 16 px / 28 px，最大行宽随字号约束为 34em。标题和题注另有层级。

原页红框已移除。当前段使用单块淡青底与左侧细线，右栏有同样的青线。原文滚动按视口中线选择当前段；点击译文定位原页。程序联动采用最长 240 ms 动画，当前段有 600 ms 淡入效果；减少动态效果偏好会关闭动画。

### 阅读成果与修正

PDF 选区提供翻译、高亮、保存摘录、添加札记的浮动操作。译文选区保存时关联所在完整原段，避免伪造原文逐词对齐。摘录与札记分开显示，均可回到原文。

右键可将单页完整段落选区作为一段、合并到上一段、忽略块、恢复自动切分。部分段落选区会提示完整选择，避免重复覆盖；跨页选区仍可保留多页摘录与高亮锚点。

译文可通过右键编辑，修改后显示朱色小点，可恢复机器译文。人工内容与块修正按文档版本保存到本地文库，机器缓存清理不会删除它们；目标语言改变时不会套用另一种语言的手改结果。

源语言检测在文档解析完成后执行。高置信度的中文/英文与目标语言相同时会禁用对读；短文本、其他语言和不确定情况保持可用。更改目标语言后重新判断，不改变界面语言。

## 三、书府：把空间还给文献

顶部改为三组：全局样式搜索框、导入菜单、文房。搜索范围放在输入框内。列表头只保留名称、计数、密度与排序，导入不再占据中栏的第二排。

默认行高 56 CSS px，标题与年份一行，作者与来源一行；一个附件不重复显示。复选框在悬停、聚焦或多选时出现，支持 Shift 区间、⌘/Ctrl 点击与全选。回车可选择，双击或 ⌘O 阅读。

选中行采用纸色凹面与墨色细线；侧栏当前项同样采用墨色。卷帙可折叠，题签按次数排序，默认六项，可展开。完成的索引状态自动隐藏，运行或失败时保留入口。

详情只保留一个阅读主按钮与一个菜单。DOI 可点击复制；附件整行打开；题签通过编辑信息维护；成果摘要可进入阅读器对应分页；摘要默认折叠。元数据文献无 PDF 时明确禁用阅读。

“未归入集合”和回收站均连接真实数据筛选。移入回收站可恢复，元数据和附件不被删除。侧栏集合与题签计数排除已删除文献。新建的锚定札记在 Dashboard 和列表中按札记计数，不再误计成摘录。

## 四、文房与英文适配

文房采用五分区单窗口：通用、阅读与外观、翻译、书府与备份、高级与诊断。保留弹窗背景隔离、焦点约束与返回焦点。

- 通用：界面语言、主题、快捷键。
- 阅读与外观：默认模式与缩放、15–19 px 译文字号、可选 PDF 宣米显示、成果标记、页边段号轨道。
- 翻译：服务配置、目标语言、补充提示词、自动翻译、释名管理、夹注实验。
- 书府与备份：完整备份、已有备份恢复、Zotero 导入入口、索引管理、回收站说明。
- 高级与诊断：本地使用记录、导出与清除统计、诊断摘要、噪声显示、机器缓存清理与阅读偏好重置。

恢复备份前检查翻译和索引是否仍在工作，避免运行中的后台任务与文库替换冲突。缓存清理保留人工译文、段落修正及永久成果；重置阅读偏好保留内容和 API 配置。

英文在同一应用内切换，包含新页面、菜单、设置、状态、快捷键说明和导出结构。日期、时长、数量与英文单复数沿用本地化规则；界面语言不改写原文、标题、笔记、译文或目标语言。英文使用系统无衬线字体，中文展示标题用 Songti SC 系统栈，正文与控件用系统 UI 字体。

朱砂用于用户札记、人工译文点和品牌；青色用于原译对应；藤黄用于高亮与摘录。系统选中态、编号和统计采用墨色，错误使用独立危险色。Dashboard 保留功能和统计口径，并统一了选中态与热力图色阶。

## 七、实际边界

PDF 是视觉格式，段落与语言识别属于保守启发式，不能承诺所有出版物自动正确。复杂多栏、扫描件、旋转、公式密集与跨栏图表仍需用真实资料复核；OCR 未新增。可查看忽略内容、恢复自动切分并保留原版。

夹注继续是实验功能。默认使用原文/对读，不默认开启实验。正式发行签名、公证、真实长读、大文库性能与完整恢复矩阵仍需专项验收。

回收站不做自动永久删除；文房只重置阅读偏好，不提供会清空文献或密钥的“一键重置”。备份/诊断入口不等同于完整运行日志浏览器。当前桌面窗口最小宽度为 900 px，不作为手机端交付。

本文件为当前实施说明。原始设计方案及历史 0.5.x 文档作为档案保留，命名、入口与本轮验收以本文件和实现为准。
