# 笺 Jian · M5 / M6 与使用概览交付

日期：2026-10-29 · 版本：0.5.0 · 数据库：schema v4 · macOS Apple Silicon 本地预览

本次在独立工作副本中并行推进 M5 日常使用打磨与 M6 单栏行间阅读，并新增应用内使用 Dashboard。原始工程和日常文库未被改写。可调 DeepSeek、Google 原生 Gemini / Gemma、自定义兼容服务和 Ollama 配置沿用并继续可用。

**当前交付状态：** M5 的本轮交互、视觉、主题、诊断和本地预览包已实现；M6 交付可运行实验原型。正式签名公证、真实大文库长读与性能验收，以及 DESIGN §12.7 的全部行间门槛仍未完成，不能把本包视为正式 V1.1 发行版。

## 1. 从哪里开始

- 本机直接打开「笺预览-0.5.0.app」。无需先安装开发依赖，适用于本次构建的 macOS arm64。
- 首次进入「概览」，没有历史时展示真实空状态。通过「进入文库」导入 PDF，再开始阅读。
- 右上「设置」可切换跟随系统 / 浅色纸墨 / 深色夜读；阅读器内可用 `⌘,` 打开。PDF 原页保持原始颜色。
- 「设置 → 打开翻译设置」可自行调整服务、基础地址、接口协议、模型 ID、API Key、超时、Temperature 和发送同意项；也可读取端点返回的模型列表。阅读器仍保留「翻译设置」入口。
- 阅读器顶部「原文 / 双语 / 行间 · 实验」切换阅读方式。行间模式只在通过检查的单栏文字页启用，逐页解释降级原因；不会自动发送文字。
- 概览提供最近 7 / 30 / 90 天及自开始记录的范围；「导出完整数据」保存全部历史 JSON，不受当前时间筛选限制。

本地预览默认使用独立 `Jian Preview` 应用数据目录，不会自动接管旧开发文库。已有文库若通过开发环境接入，必须使用新版并保留完整备份。不要用旧版程序打开已升级的 schema v4 文库。

## 2. 交互冲突与按钮卡片

本轮修复的不是静态样式问题，包含实际的操作竞争和状态错误：

| 冲突 | 修复后的行为 |
| --- | --- |
| 弹窗打开后背景仍可点击、快捷键穿透、Tab 离开弹窗 | 背景 inert；仅顶部弹窗响应 Escape/Tab；关闭后恢复原按钮焦点；文库/阅读器全局快捷键避开弹窗。 |
| 搜索迟到响应覆盖新查询 | 用请求代次丢弃旧响应；输入立即清除旧结果，分页防重入。 |
| Enter 创建集合后失焦再次创建 | 显式提交、取消与同步锁，一次操作只创建一项。 |
| 复选框覆盖标题、Space 同时切换当前文献 | 独立的可见 16 px 复选框；勾选与打开文献互不干扰。 |
| 并发拖放导入、旧详情仍能短暂操作 | 共享操作锁、弹窗隔离和详情身份校验。 |
| 导出失败仍停在“正在生成”、重复保存 | 加载与失败分开；失败有说明，保存禁用；进行中的保存防重入。 |
| 窄窗口详情栏挤压列表 | 详情与列表分层切换；Dashboard 导航在窄窗转为完整横向入口。 |
| 行间工具栏状态在右侧截断 | 明确网格、独立状态行、换行与边界限制，按钮不会相互覆盖。 |
| 深色译文背景仍为固定浅色 | 全部改用有效主题 token；原 PDF 白纸保留，译文和操作区域随主题切换。 |
| 同一行间段落反复点击“译” | 生成期间该入口禁用，避免同段并发重译。 |

视觉采用暖纸、墨色、少量低饱和强调色；宋体用于标题和主要数字，无衬线用于操作与正文。用留白、细分隔线和对齐建立层次。通用按钮 34 px，紧凑按钮 30 px；页边入口 28 × 32 px。Dashboard 汇总采用连续分栏，避免把所有信息都包装成重复的大圆角浮层卡片。

悬停、当前项、按下、禁用与键盘焦点各有明确状态。弹窗保留固定标题与底部操作区，长表单独立滚动。API 高级字段折叠，常用配置保持可见。

时间筛选作用于活动和用量；文库存量及分类篇数始终是当前快照，并在界面标明。7 / 30 / 90 天为滚动小时范围，趋势按本机 IANA 时区切分当地日期。图表从零开始，可查看日期表格；长区间合并相邻日期，保留区间说明。

概览研究分布展示前 8 项，研究方向页最多各 50 项；阅读明细最多 100 个文档版本。完整原始计量与分类可导出。多话题、标签或集合会重叠，不能直接相加为总时长或总文献数。

### 统计口径

1. **有效阅读不是打开文献的时长。** 阅读器约每 5 秒采样，主进程复核窗口焦点、可见、未最小化、系统闲置少于一分钟；弹窗、失焦、休眠、锁屏和超过 15 秒断档均中断累计。首次打开仅计访问，不计时长；最后未采样的几秒不追补。
2. **字数是页面文字覆盖代理。** 按文档版本＋页去重，使用本地索引可提取内容；不能称为逐字阅读或已理解。扫描页、未索引页不会凭空补字数。字符与混合语言词数单独展示，不能相加。
3. **Token 按真实网络尝试记录。** DeepSeek/兼容接口读取 `usage`，Google 读取 `usageMetadata`，Ollama 读取完成事件计量。流式累计字段更新而不重复求和；共享请求和缓存不会重复计费式累加，重试另记一次尝试。
4. **未知与零不同。** 未回传为未知；实际回传零保留零。字符估算独立展示，不混入服务回传总量。缓存和推理细项可能属于输入/输出，不再次加总。
5. **费用、余额与额度没有账单来源。** 当前明确显示“暂无账单数据”；不根据估算伪造费用。升级之前未记录的阅读与 Token 不倒推补齐。

统计只存在本机 SQLite。使用数据导出不含 Key、认证头、正文、标题、完整 URL 或文件路径；包含模型、服务主机、时间、计量、文献标识和分类。默认开启，可随时暂停。清除需二次明确确认，保留文献、摘录、分类和 API 配置；旧的在途请求不会在清除后恢复旧用量。整库备份遵循原有规则，包含统计数据库，密钥仍另存并不进入普通备份。

## 4. M6 行间模式的交付边界

新增独立页面适配器，保留稳定原页渲染器。原页从上至下划分连续全宽片段，每个片段保留源 / 目标矩形与插入高度；译文空间不会生成伪 PDF 锚点。文本选择、已存高亮、搜索命中和链接使用同一个分段映射。

原文使用 PDF.js 真实文字层和源画布切片，源像素只复制一次；译文采用独立 DOM 排版。单页源缓冲与全部切片预算 48 MiB，DPR 上限 2；这是单页限制，不代表整个应用内存承诺。长译文不生成无限长合成画布。

图片 / 矢量图形、旋转、双栏、低置信度、重叠、文字跨切线、嵌套标记文字层等页面保守回到原版，并保留双语面板。行间模式重启后恢复稳定双语与同一原文位置。

本轮合成夹具中，源图像回填像素差异 0；1248 字流式译文插入后源点漂移 0 CSS px；局部、跨段、跨页选区、两个页锚点、查找、高亮、外链区域及 80% / 200% 缩放通过。同页滚动检查点与重载后原文位置一致。非零 CropBox 测试通过；90°旋转页验证保留原版，180°/270°仅完成几何拒绝单测。

自然论文识别率、复杂公式/脚注/字体、内部精确 destination、多 DPR/缩放手势、快速切换及超长文档总内存压力仍需专项。实验入口不会被默认开启；这些限制不会被本轮专项通过所掩盖。

## 5. 验证与证据

- 40 项自动测试全部通过，包含旧库迁移一致快照、缓存/取消/重试、三个协议计量、未知/零、跨午夜/夏令时及 M6 几何与像素切片。
- TypeScript 严格检查、生产构建通过。
- M3 Google 原生协议与旋转页翻译/摘录/缓存/后台任务回归通过；M4 查找、元数据、五种导出回归通过。
- M5 弹窗隔离、键盘焦点、集合、复选框、故意延迟的旧查询、导出错误及窄窗详情回归通过。
- Dashboard 全新空库与有数据状态均通过；分类保存、统计开关、取消清除、完整 JSON 导出、深浅色、窄窗导航与页面不溢出通过。
- 阅读采样联调累计约 10 秒，弹窗 / 最小化 / 离开阅读器后的增量均为 0。无人值守环境无法抢占系统前台，**该联调的焦点与系统闲置传感显式受控**；真实渲染器、弹窗、最小化、IPC 与数据库链路保留。原生前台行为和长时间真实阅读仍需人工验收。
- 行间工具栏 1280 / 960 × 浅 / 深四组检查：文档无横向溢出、按钮交叠为 0、状态完整可见。实测浅色 / 深色译文正文对比度分别 14.88:1 / 14.12:1，活动页边入口为 13.59:1 / 11.55:1。
- macOS 预览包采用本地 ad-hoc 签名，通过本地签名完整性验证；没有 Developer ID 签名、公证或自动更新。

截图与测试明细见随包 `docs/m5-m6-evidence/`。**有数值的 Dashboard 截图来自明确隔离的确定性测试数据，不是用户真实阅读、真实账单或生产占位数据。** 安装包没有预装该测试文库，也没有把这些数字写入应用的默认状态。未使用用户真实 API Key，也未向真实云端发送论文。

## 6. 开发继续与发布门槛

源码包含构建产物，不包含开发依赖、用户文库和密钥。开发环境执行 `pnpm install --frozen-lockfile` 后可运行 `pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm start`。测试脚本全部使用独立 `JIAN_TEST_ROOT`，详情见 HANDOFF。

schema v4 增量增加使用计量和分类表，升级前自动创建一致数据库快照；快照不复制附件，不能替代完整备份。不可用旧 schema 程序写入新库。

后续发布必须完成：真实论文持续阅读与异常恢复、大文库/长文档性能与进程总内存、旧库完整升级恢复、最终应用身份与图标、Developer ID 签名公证和 DESIGN §12.7 未完成门槛。M2 历史边界（外链重新定位、孤立 blob 清理、来源关系移除/冲突 UI）继续保留，不因本轮交付自动关闭。
