# 笺 · Glossleaf 0.9.2：交互与滚动修复

2026-10-30。本轮根据八项界面反馈，在 0.9.1 独立副本上完成修订。工程入口见 [开发交接](../HANDOFF.md)，英文使用见 [Getting started](GETTING-STARTED-en.md)。原工程和真实文库未修改。

## 本轮修改

| 反馈 | 完成的调整 |
|---|---|
| 小传导航图标穿模 | 图标固定占据独立的 18px 列，与文字保持 12px 间距；中英文、底部入口使用同一结构。 |
| 研究方向等内容无法向下滚动 | 修复根容器与路由内容的高度约束；小传内容区和侧栏独立滚动，所有栏目底部可达，切换栏目返回页首。设置长页也检查到底。 |
| 选中蒙版异常 | 区分悬停、正在按压、持续选中和键盘焦点；移除不分场景的 aria-expanded 蒙版。导航、设置分类、热力图切换都有明确当前状态。 |
| 顶栏“全部”死板 | 改为独立浅青色圆角按钮，范围菜单有当前选中勾记；保留原检索范围和键盘操作。 |
| 按钮太方、颜色单调 | 动作控件采用 8–12px 圆角、细边界和轻投影；以青色作交互和热力图强调，辅以朱色、赭色统计值，保留纸面底色与克制顶栏。 |
| 选区工具栏不清楚 | 改为带文字的复制、高亮、批注、翻译、粘贴和收起；工具有明确按钮边界，浮层随视口和内容变化调整位置。 |
| 朱批标识像头发丝 | 换成 16px 对话气泡图标和 28px 点击区，低饱和朱色底；保留聚合数量、点击编辑和自动保存。 |
| 动作与展示内容混淆 | 研究话题行恢复普通内容，单独用检索按钮执行动作；静态文字与统计值不套按钮外观。返回、关闭等动作有可见边界。 |

## 选区与粘贴的使用方式

选中原文后可直接复制。复制保留选区文字与换行；高亮、批注引用和翻译继续使用原有规范化文本及源坐标锚点。选区底色改为按行合并绘制，避免原生逐字覆盖叠成深浅斑块。绘制合并不更改保存的锚点，旋转和实验夹注沿用已有坐标映射。

点击“粘贴”把剪贴板文字放入此处的朱批编辑器，600ms 空闲后自动保存；PDF 原件保持只读。编辑器内仍支持系统粘贴快捷键。只有点击工具栏粘贴时才读取剪贴板；空内容或超过 50000 字符会显示行内提示。新建时预填的文字进入保存队列，不会被错误当作已经保存。

## 视觉尺度

继续采用 60px 应用顶栏和 17px 阅读标题，窄窗为 16px。系统红黄绿窗口控件仍处于应用内容之外的原生标题栏。字体延续宋体与 Source Serif 4，不通过再次放大字号解决按键问题。

按钮效果只用于动作：有边框、圆角、悬停色，按下时轻微下移并出现内阴影。持续选中有独立浅青色面与边界，键盘焦点另有轮廓。研究方向、普通正文、统计值与无交互的图标保持展示语义。

## 开发与兼容

- 当前样式最后由 controls.css 收口，主容器采用窗口约束的纵向 flex；长内容由各面板自行滚动。
- 新增受信 clipboard:readText 入口；原有文件授权、原件引用、批注修订与模型配置不变。
- schema 保持 6，无本轮数据库迁移。升级前退出旧版，避免同时打开同一文库。
- 本地及 Zotero 导入仍直接关联原件；在线取得的全文保存一份。缓存、索引和显式备份仍占用正常空间。
- macOS arm64 预览采用 ad-hoc 本地签名，尚未公证。


## 最终验收结果

86 项数据与单元测试、类型检查与生产构建通过；10 组原生桌面回归全部通过。新增专项覆盖中英文 900/1280 宽度的导航间距、四个小传栏目滚轮滚动、最终内容可达、设置四个长页面、搜索范围切换、真正的 :active 按压状态、选区复制换行、粘贴自动保存、朱批标识与 PDF 原件哈希。现有批注、引用、原件关联、中文 PDF、缩放与实验夹注继续通过回归。

打包应用与构建逐文件比对一致，本地签名验证和隔离英文冷启动通过。未调用付费模型，未重新验证真实出版社下载。DPR 1/2/3 为 Chromium 设备参数模拟，并非三台物理显示器；滚轮与鼠标按压由原生 Electron 窗口中的输入协议驱动。数值与截图保存在 evidence-0.9.2/verification.json 及各专项证据目录。
