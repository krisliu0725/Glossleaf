## 2. 命名与主题统一（对应你的第 5 点与最新要求）

### 2.1 命名原则

1. **中文来自"信笺的世界"**：笺（小幅纸）、札（书札）、函、帙、签、文房。每个名字都能追到一个与书信、纸、批注、藏书有关的古典词。
2. **英文是单个常见词**：像 Haiku / Sonnet / Opus 那样，一个词本身就像一个诗题，同时不用查词典就能懂；不造词，不用冷僻词。
3. **名词给"地方和模式"，动词给"动作"**：导航、标签页、面板用文雅名；按钮保持直白命令（"翻译本页 / Translate Page"）。危险与恢复性操作永远用标准词（永久删除、恢复备份）。
4. **一个概念只有一个名字**：不允许同一功能在不同页面出现两种叫法。

## 3. 阅读页重构（展笺 Reader）

### 3.1 设计原则

- **PDF 是主角**：不在原文上叠加任何边框；联动只用一种方式表达。
- **段落是唯一单位**：对应、翻译、缓存、摘录都以"段落块"为单位。
- **右栏只放右栏该放的**：译文。原文已经在左边了。
- **控件默认隐藏，需要时出现**：悬停、选中、右键、快捷键。

### 3.2 布局（对读模式）

```
┌────────────────────────────────────────────────────────────────────────────┐
│ ‹ 书府    人工智能时代的生物安全治理…     1 / 13      [ 原文 | 对读 ]    ⌕   ◫   ⋯ │
├──────────────────────────────────────┬─────────────────────────────────────┤
│                                      │  笺注      札记      撷英              │
│                                      │                                     │
│      ┌───────────────────────┐       │  ┃ 摘要                              │
│      │ PDF 页面              │       │  ┃ 人工智能时代的生物安全形势复杂、    │
│      │                       │       │  ┃ 风险叠加，不确定性与不可预测性      │
│    ┃ │ 摘要 ……（当前段落）      │       │  ┃ 增强……                           │
│      │ 淡青底 + 左侧 2px 青线   │       │                                     │
│      │                       │       │    当前，智能生物科技军事化对国际    │
│      │ 当前，智能生物科技……     │       │    战略稳定构成冲击……               │
│      └───────────────────────┘       │                                     │
│                                      │    一、人工智能时代生物安全风险的    │
│                                      │    新特点                            │
│                                      │                                     │
│                                      │  deepseek-flash · 已译 3 / 13 页      │
└──────────────────────────────────────┴─────────────────────────────────────┘
```

- 默认分栏 55 : 45，可拖动分隔线，位置记忆。
- **原文模式**：右栏收起，PDF 水平居中，最大宽度 920pt，左右留白对称（解决 K）。
- 右栏底部的状态行是唯一的"引擎信息"：10 号字、辅助灰，点击进入文房 › 翻译。

### 3.3 顶栏：11 个控件 → 6 个

| 位置 | 控件 | 去向 |
|---|---|---|
| 左 | ‹ 书府（返回） | 保留 |
| 左 | 标题（截断） | 保留，不可点击 |
| 中 | 页码 `1 / 13`（点击可输入） | 保留，字体改为系统等宽、辅助灰 |
| 中 | 分段控件 `原文 | 对读` | 保留；**"行间·实验"移除** |
| 右 | ⌕ 查找（⌘F） | 保留，图标按钮 |
| 右 | ◫ 侧栏开关（⌘\\） | 新增，取代顶栏的"札记""译注设置"两个文字按钮 |
| 右 | ⋯ 更多 | 新增，内含：缩放（⌘+ / ⌘- / ⌘0，同时支持触控板捏合）、夹注（实验，仅在开启后出现）、打开文房 |
| — | 中文 / EN | **移入文房 › 通用**（界面语言不属于阅读工具栏） |
| — | 100% 缩放下拉 | 移入 ⋯，并保留快捷键 |
| — | 札记（顶栏文字按钮） | 改为右栏标签 |
| — | 译注设置 | 改为文房 › 翻译 |

### 3.4 右栏：8 个控件 → 3 个标签 + 1 个动作

**标签**：`笺注 · 札记 · 撷英`。
"释名"（术语表）不再占标签位：在文房 › 翻译 › 释名管理；在笺注中悬停术语时出现小气泡（青色下点线标记术语）。

**翻译动作：一个状态按钮取代三个按钮。**

| 状态 | 按钮（位于右栏顶部，仅在需要时出现） |
|---|---|
| 当前页未翻译 | `翻译本页  ⌘T`（主按钮，深墨底） |
| 正在翻译 | `停止`（描边按钮）+ 一条 2px 青色细进度线贴在栏顶 |
| 当前页已翻译 | **按钮消失**，不留位置 |
| 部分失败 | 栏顶一行小字 `3 段未完成 · 重试`（危险色文字，非仅靠颜色，带图标） |

- "整篇翻译"移入 ⋯ 菜单（快捷键 ⌘⇧T），并在首次翻译完成后用一次性小提示告知。
- 文房 › 翻译中提供"打开对读时自动翻译当前页"，默认**关闭**（云端模型有成本，不要替用户做决定）；原"跟随段落"改为**始终跟随**，不再有开关。

### 3.5 段落切分规范（解决问题 1）

**单位**：段落块（Block）。

| 块类型 | 判定要点 | 默认行为 |
|---|---|---|
| 标题 title | 字号最大、居中、首页顶部 | 翻译 |
| 摘要 abstract | 以"摘要 / Abstract"引导 | 翻译 |
| 关键词 keywords | 以"关键词 / Keywords"引导 | 翻译，样式紧凑 |
| 小节标题 heading | 字号大于正文、行短、编号开头 | 翻译 |
| 正文段 body | 首行缩进或段间距增大为段界 | 翻译 |
| 图表题注 caption | "图 n""表 n"开头 | 翻译 |
| 脚注 footnote | 位于页脚、字号小、编号开头 | 默认折叠，可展开 |
| 参考文献 refs | 位于"参考文献 / References"之后 | 默认不翻译 |
| **噪声 skip** | 页眉、页脚、页码、DOI 行、作者简介、基金项目、期刊刊名行 | **默认不翻译、不显示**；在 ⋯ 菜单中有"显示被忽略的内容"开关 |

**切分算法要点**

1. 先按行聚类，再按以下信号划分段界：垂直间距 > 0.6 倍行高、首行缩进、字号变化、列变化。
2. **跨栏、跨页合并**：上一栏或上一页末行不以句末标点结束、下一块首行无缩进，则合并为同一段。
3. **重复检测页眉页脚**：同一 y 区间在 ≥ 3 页出现相似文字，则标为噪声（本例"人工智能与数字社会 2026 年第 2 期"即会被识别）。
4. **文本规范化**（解决 G）：
   - 删除相邻汉字之间、汉字与全角标点之间的多余空格；
   - 英文连字符断行（`inter-\nnational`）合并；
   - 软换行转为空格（英文）或直接连接（中文）。
5. **翻译上下文**：提交块时附带上一块标题与术语表，保证术语一致；缓存键 = 块规范化文本哈希 + 引擎 + 目标语言 + 释名版本。
6. **源语言检测**（解决 H）：整篇检测一次；若源语言与目标语言相同，`对读` 置灰，悬停提示"这篇文献已是中文，无需翻译"。
7. 切分结果允许用户修正：在 PDF 上拖选一段文字，右键 `作为一段 / 合并到上一段 / 忽略此块`。修正写入该文献的块表，不覆盖原 PDF。

### 3.6 联动与对应（解决问题 2）

**删除**：PDF 上所有红色方框（句框、关键词框、悬停框）。

**新的对应方式——只有一种**：

| 动作 | 效果 |
|---|---|
| 阅读时滚动 PDF | 视口中线所在段落自动成为"当前段"：PDF 上该块出现 `--jian-teal-soft` 底色（带 `mix-blend-mode: multiply`，不遮字）+ 块左侧 2px 青线；右栏对应段落同样出现 2px 青线，并平滑滚到视口上 1/3 处 |
| 点击右栏某一段 | PDF 滚到该块，块底色闪现 600ms 后停在"当前段"状态 |
| 点击 PDF 某一块 | 右栏滚到对应段 |
| 悬停但未点击 | 仅该块出现 4% 青色浅底，无线条 |

**页边数字轨道（F）**：

- 默认只显示**当前段的序号**（10pt 等宽、青色），其余段只有一个 4px 的辅助灰短横标记位置；
- 悬停轨道时才显示所有序号；
- 序号只用于定位，不进入右栏，右栏不再出现 `1·01`。

### 3.7 右栏译文排版（解决问题 2 的"字体与排版"）

| 项 | 规格 |
|---|---|
| 字体 | 系统字体 PingFang SC（见第 7 节），**不再使用等宽字体做内容**；正文墨色 `--jian-ink`，**不是**青色、不是灰色 |
| 字号 / 行高 | 16px / 28px（沿用开发文档） |
| 栏宽 | 最大 34em（约 540px），超出居中，避免行过长 |
| 段间距 | 20px；标题块上方 32px、下方 12px |
| 标题块 | 小节标题 17px / 600；论文标题与摘要标题可用 Songti SC 600，仅限这两处 |
| 当前段 | 左侧 2px 青线，线与文字间距 14px；其余段不加线，仅文字 |
| 段落内标点 | 使用全角；译文中的专有名词首次出现可在括号中带原文，由翻译提示词控制 |
| 未翻译段 | 不显示原文；只显示一条 1px 虚线占位，悬停时出现 `翻译此段` 幽灵按钮（文字按钮、无边框、辅助灰） |
| 翻译中段 | 两行 shimmer 骨架（不使用旋转器） |
| 失败段 | 一行危险色小字 `未能翻译 · 重试`，带 ⚠ 图标 |
| 悬停已译段 | 右上角出现 3 个 20px 图标：复制、重译、保存为撷英（均有 tooltip）。**"更多"取消**，其他罕见操作放右键菜单 |
| 用户改过的译文 | 段尾出现 6px 朱色点（朱砂 = 用户所写），悬停可"恢复机器译文" |

### 3.8 选中文字工具条（取代"到处都是按钮"）

在 PDF 或译文中选中文字，出现一个 36px 高的浮动条，四个图标，均带文字 tooltip：

`翻译选区` · `高亮` · `保存摘录` · `添加笔记`

- 高亮用藤黄；保存摘录后左侧出现藤黄书签标记；添加笔记后出现朱色页边标记；翻译选区的结果以小气泡显示（青色细线），不进入右栏的段落流。
- 键盘：`⌘T` 翻译选区/本页、`⌘E` 保存摘录、`⌘⇧N` 添加笔记。

## 7. 视觉规范（采纳品牌规范，字体除外）

### 7.1 色彩语义（沿用 `tokens.css`，补充使用边界）

| 色 | Token | 只用于 | **禁止用于** |
|---|---|---|---|
| 玄墨 | `--jian-ink` | 正文、译文、主按钮、选中态、当前项 | — |
| 宣米 | `--jian-paper` 系 | 应用背景、抬升与凹陷面 | PDF 页面（保持原件颜色） |
| 朱砂 | `--jian-vermilion` | 用户所写（札记标记、用户修改过的译文点）、品牌图标上的页边记号 | 系统编号、选中态、悬停框、错误 |
| 黛青 | `--jian-teal` | 原译对应（当前段线与底）、页边当前序号、术语下点线、翻译进度线 | 整栏译文着色 |
| 藤黄 | `--jian-ochre` / `--jian-ochre-ink` | 高亮、撷英标记；浅底上小字用 `ochre-ink` | 正文装饰 |
| 危险 | `--jian-danger` | 失败、删除确认，必须带图标或文字 | 仅靠颜色表达 |

### 7.2 新增 token（建议加入 `tokens.css`）

```css
:root {
  /* 阅读联动 */
  --jian-block-active-bg:   var(--jian-teal-soft);
  --jian-block-active-rule: var(--jian-teal);
  --jian-block-hover-bg:    color-mix(in srgb, var(--jian-teal) 4%, transparent);
  --jian-block-rule-width:  2px;

  /* 译文栏 */
  --jian-gloss-size:        16px;
  --jian-gloss-leading:     28px;
  --jian-gloss-measure:     34em;
  --jian-gloss-para-gap:    20px;

  /* 列表 */
  --jian-row-height:        56px;
  --jian-row-selected-bg:   var(--jian-paper-inset);
  --jian-row-selected-rule: var(--jian-ink);
}
:root[data-theme="dark"] {
  --jian-block-hover-bg: color-mix(in srgb, var(--jian-teal) 8%, transparent);
}
```

PDF 联动底色使用 `mix-blend-mode: multiply`（深色主题下改用 `screen` 并降低不透明度），不遮挡文字。

### 7.3 字体（不采纳品牌规范的字体方案）

| 用途 | 字体 | 说明 |
|---|---|---|
| 界面与译文 | **系统字体**：`-apple-system, "PingFang SC", "Helvetica Neue", sans-serif` | 不随包分发字体，无授权问题 |
| 展示用标题（论文标题、"笺"字标、空状态标题） | **Songti SC**（macOS 自带） | 你现有截图里标题看起来就是宋体系，我按此沿用；**请核对你代码里实际使用的字体**，以代码为准 |
| 页码、段号、DOI、快捷键、计数 | 系统等宽 `ui-monospace, "SF Mono"` | 仅用于"数字类"信息，不再用于任何内容文字 |
| 英文界面 | 系统字体，同上 | 品牌规范里的 Source Serif 4 / Georgia 不采纳 |

> 原则：宋体只在"值得被看见的标题"出现，长时间阅读的译文用无衬线，对屏幕更友好；两者靠字号和字重区分层级，不靠颜色。

### 7.4 图标

- 继续使用品牌包的 24×24 / 1.75 描边 / `currentColor` 图标，以内联 SVG（SVGR）引入。
- 顶栏与工具栏图标默认墨色；**仅在激活状态**才出现语义色（对读激活为青、札记标签激活为朱、撷英标签激活为藤黄）。
- 图标映射：书府 `library`、展笺 `reader`、对读 `bilingual`、撷英 `excerpts`、札记 `notes`、考索 `search`、设置 `settings`、导入 `import`、卷帙 `collections`、释名 `glossary`、征引 `citations`、回到原文 `back-to-source`。
- 品牌包缺少的图标见附录 C。

### 7.5 状态、动效与可访问性

- 动效只有三种：段落联动平滑滚动（≤ 240ms，`prefers-reduced-motion` 下取消）、当前段底色闪现（600ms）、翻译进度线。
- 所有仅图标按钮必须有 tooltip（含快捷键）与 `aria-label`。
- 不仅靠颜色传达状态：失败 = 图标 + 文字；已译 = 文字或圆点 + tooltip。
- 对比度：文字与图标 ≥ 4.5:1；青色底上不放小字；藤黄浅底小字使用 `#8D6A22`。
- 点击区域 ≥ 32 × 32px，即便图标只有 18–20px。
