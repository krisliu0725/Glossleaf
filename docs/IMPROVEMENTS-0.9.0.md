# 笺 · Glossleaf 0.9.0 · 批注与品牌更新

2026-10-30。基于 0.8.0 独立开发，落实批注 v1.2、UI v2.1 与 Logo Colorways V3。原项目和真实文库未修改。

## 阅读时留下轻而清楚的痕迹

右栏统一为“笺注 / 札记”（Translation / Notes）。选区只保留高亮、朱批、翻译三个入口；颜色选择收在高亮分钮中。高亮支持七套六色色谱、编号快捷键 1–6、H 重用当前颜色；透明度默认 40%，可调 25%–55%。新色谱只影响之后的高亮，已有颜色与 Zotero 来源色保留。

朱批在 PDF 内浮层编辑，停笔 600ms 自动保存。N 对选中文字写批注，没有选区则在页面落点，也可用于扫描页。附近标记聚合后可逐条打开。编辑不切走右栏笺注，不重置阅读位置；关闭后焦点返回页边标记。删除高亮保留关联朱批；会话内支持创建、编辑、改色和删除的撤销重做。

统一札记按全部、撷英、朱批筛选；高亮、译文及相关评论归组展示。可以复制、导出当前筛选或勾选项目为 Markdown。朱批正文可搜索并返回原页；原有 APA、MLA 等引用、RIS/BibTeX/CSL-JSON 与备份能力保留。

## 品牌与页面

使用补充包中的 V3 图形，保留两路径及真实透明间隙。中文显示图形＋笺，英文为图形＋Glossleaf。六配色支持明暗主题，品牌选择和高亮色谱各自独立；Dock 使用固定默认墨朱。

保留中文宋体与离线 Source Serif 4，继续沿用书府 / 小传两主页。列表提供紧凑与宽松密度，紧凑最小 56px，长标题最多两行。左侧选中态采用浅墨底、短线和文字强调；箭头、菜单与按钮使用统一组件。PDF 原译联动只显示细线，移除大面积青色选中背景。

## 数据与原件

批注仍写入本机数据库，不改原 PDF。本地和 Zotero 文件继续关联原件，在线获取全文只保存一份。旧高亮内的评论迁移成独立朱批，重复打开不会再拆一次；高亮关联不决定朱批生存期。未知 Zotero 批注保留只读来源内容，不伪造为可编辑文字高亮。

schema 从 5 升为 6。升级前退出旧版本并做完整备份；自动迁移快照只含元数据，不能替代附件备份。0.8.0 及更旧版本无法打开升级后的文库。撤销历史限当前阅读会话；Markdown 用于阅读成果交换，完整恢复请使用文库备份。

## 交付与验收

验收明细与原始结果在 evidence-0.9.0/verification.json。覆盖类型检查、生产构建、85 项单元/数据测试、原生应用回归、色谱计算、预览包冷启动。桌面测试采用隔离合成文献和本地模拟服务，没有使用个人文献或付费模型。

五类 PDF 包括中文、双栏、公式、图表和扫描页；覆盖跨页选区、50%–400% 缩放及四方向旋转。DPR 1/2/3 使用原生 Electron 窗口的 Chromium 设备参数模拟，不能视为三台物理屏幕实测。性能数据仅适用于随包测试集及当次机器。

macOS arm64 预览应用使用本地 ad-hoc 签名，尚未正式签名与公证。开发包提供源码、构建、测试、锁文件、设计原文、Logo 资源与说明；不含依赖目录、密钥、个人原件或用户数据库。

## 后续范围

单文献色谱、语义槽名、全文无锚札记、Word/PDF/CSV 导出、替换文件后的批注迁移确认、页边连线按 v1.2 留待后续。没有新增 OCR 或自动改写 PDF。规格取舍详见 [实施审查](ANNOTATIONS-P0-0.9.0.md)，工程接续见 [开发交接](../HANDOFF.md)。

## 最终验收结果

85 项测试、类型检查与生产构建通过；八组桌面回归全部通过。三种模拟 DPR 共 48 组缩放/旋转组合，高亮坐标误差均小于 1 个设备像素。页边朱批的创建、编辑、删除及撤销重做、相邻聚合、焦点返回、扫描页落点、导出和搜索通过。夹注模式的源像素逐字节比较无差异，点状朱批随插入译文映射正确。中文/英文、明/暗主题、900/1280 宽度检查通过；英文界面残留检查为空。

打包后的构建文件逐一比对一致，ad-hoc 签名验证与隔离英文冷启动通过。色谱、迁移和备份证据随包。测试未访问用户文库，原始 PDF 哈希保持不变。详细数值见 evidence-0.9.0/verification.json。
