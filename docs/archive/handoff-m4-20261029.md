# 笺 Jian · M4 交接说明

日期：2026-10-29 · 版本：0.4.0 · 数据库 schema：v3

M4「查找与带走」核心流程已交付。保留 M0–M3 与 0.3.1 的可调整 DeepSeek / Google Gemma 4 / Gemini API 设置。复杂真实文献、受密码保护 PDF、超大文库和正式发行仍有边界，详见 `docs/M4-验收与使用说明.md`。

## 启动

```bash
pnpm install --frozen-lockfile
pnpm typecheck
pnpm build
pnpm start
```

代码包含预构建 `out/`，不含 `node_modules`、用户文库与密钥；首次仍需安装依赖。沿用项目的 Electron 45.1.0 / PDF.js 6.4.299 / React 19.3.1 / TypeScript 5.9.3。新增生产依赖 citeproc 2.4.63；Citation.js core/plugin-bibtex 0.7.21 仅用于独立解析回归。

开发时设置独立 `JIAN_LIBRARY_DIR`，避免把测试夹具混入日常文库。启动包装会清除继承的 `ELECTRON_RUN_AS_NODE`。

## 主要入口

- 文库搜索：全部 / 文献 / 正文 / 摘录；`⌘⇧F` 聚焦全局搜索。
- 文库索引状态行：后台本地抽取、暂停、更新重试与失败原因。
- 搜索正文或摘录命中：打开文档版本、页码与片段位置；阅读器 `⌘F` 查找本文。
- 「通过 DOI 添加」：Crossref 查询 → 可编辑预览 → 用户确认入库；同 DOI 默认阻断重复。
- 详情「编辑信息」「复制引用」「引用与导出」；列表勾选可导出多篇。
- 五类输出：CSL-JSON、BibTeX、Markdown 摘录、JSON 摘录、GB/T 7714-2015 顺序编码参考文献。
- API 设置仍在阅读器右上角「翻译设置」，说明见 `docs/API-配置说明.md`。

## 数据升级

- v3 是增量迁移，保留旧的用户数据和原有检索探针表。
- 升级既有文库前，在 `migration-snapshots/` 创建一致的升级前数据库快照。它不复制附件；实际用户升级前仍应保留完整备份。
- 索引是可重建数据；摘录、评论、译文记录与元数据不是缓存。
- 不要用 schema v2 的旧程序打开已经升级的 v3 文库。API 密钥仍按端点加密保存在 `.secrets/profiles.enc`，不进入 SQLite 或完整备份。

## 验证

```bash
pnpm test
pnpm typecheck
pnpm build

# 每次使用全新的目录
env -u ELECTRON_RUN_AS_NODE JIAN_TEST_ROOT=/tmp/jian-m4-normal \
  ./node_modules/.bin/electron scripts/m4-e2e.cjs

env -u ELECTRON_RUN_AS_NODE JIAN_TEST_VARIANT=rotate \
  JIAN_TEST_ROOT=/tmp/jian-m4-rotate \
  ./node_modules/.bin/electron scripts/m4-e2e.cjs

# 原 M3 Google 协议回归
env -u ELECTRON_RUN_AS_NODE JIAN_TEST_PROVIDER=gemini JIAN_TEST_VARIANT=rotate \
  JIAN_TEST_ROOT=/tmp/jian-m3-regression \
  ./node_modules/.bin/electron scripts/e2e.cjs
```

结果：26 项自动回归、严格类型检查与生产构建通过；M4 普通/旋转 PDF 的真实 Electron 流程通过；M3 Google/Gemma 原生协议和阅读闭环回归通过。CSL-JSON 与 BibTeX 经独立 Citation.js 解析器读回。公开示例 DOI 的真实 Crossref 查询另行通过。

自动测试使用本机模拟翻译服务、合成 PDF 和固定 DOI 响应；没有向模型发送真实文献。严格沙箱运行 HTTP 测试需允许本机监听。截图与摘要见 `docs/m4-evidence/` 和 `docs/screenshots/m4-*`。
