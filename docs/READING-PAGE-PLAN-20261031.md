# 阅读页改版方案：工具栏、页码、朱批

> 适用对象：书府 PDF 阅读页（朱批、札记、对读、引用导出等已有功能）
> 说明：本方案按交互与结构编写，与技术栈无关。未见源码，涉及实现的地方只给原则和数据结构，落地时请对照现有代码调整。

---

## 一、现状问题（来自三张截图）

| 编号 | 问题 | 表现 |
|---|---|---|
| P1 | 工具栏冗余 | 顶部两条工具栏约占 140px 纵向空间；"高亮、批注"在工具栏和选区浮层里各有一份 |
| P2 | 选区浮层过重 | 两行六个按钮，带标题和关闭键；出现在选区上方，会盖住小节标题和正文 |
| P3 | 页码框死板 | 带边框的输入框，像表单控件，与"书府"的纸质气质不搭；只能输入，不能浏览 |
| P4 | 朱批流程重 | 侧栏写批注像填表，没有"随手记"的感觉 |
| P5 | 弹窗遮挡 | 之前的弹窗式批注会盖住被批注的文献 |
| P6 | 文案不统一 | 图3 为 "Margin Notes · Page 13 / View in Notes / Delete"，图2 为"朱批 · 第2页 / 在札记中查看" |

## 二、设计原则

1. **阅读区优先。** 任何界面元素都不得长期占用或遮挡正文。
2. **记录与回顾分离。** 写批注在页边完成（轻、快）；回顾、检索、导出在札记里完成（全、深）。
3. **按使用频率分层。** 高频动作一步可达，低频动作收进菜单。
4. **纸感一致。** 线性图标、墨色为主、朱砂色只给"当前状态"与"重点"，不加底色块。
5. **中文统一。** 所有界面文案、提示、快捷键说明统一为中文。

## 三、方案一：工具栏（一条顶栏＋一个浮动工具坞）

### 3.1 版面

```
顶栏（单条，约 44px，滚动时淡出，鼠标靠近顶部再出现）
┌──────────────────────────────────────────────────────────────────────┐
│ ‹书府  区块链与人工智能驱动的…     第2页 / 8     [原文|对读] Aa 札记 导出 ⋯ │
└──────────────────────────────────────────────────────────────────────┘
 ▔▔▔▔▔▔▔▔▔ 2px 朱砂色阅读进度线 ▔▔▔▔▔▔▔▔▔

底部居中浮动工具坞（默认收起为一枚笔头，点击或按 T 展开）
        ╭─────────────────────────────────────────╮
        │ ↖选择  ✎高亮●  U下划线  ✐批注  ⌫橡皮 │ ↶ ↷ │
        ╰─────────────────────────────────────────╯
```

### 3.2 各区职责

| 区域 | 内容 | 说明 |
|---|---|---|
| 顶栏左 | 返回书府、文献标题 | 标题过长省略，悬停显示全名 |
| 顶栏中 | 页码胶囊 | 见方案二 |
| 顶栏右 | 原文/对读、视图（Aa）、札记、导出、更多（⋯） | 共 5 个入口，不再平铺其他按钮 |
| 工具坞 | 选择、高亮、下划线、批注、橡皮、撤销、重做 | 只放"标注类"工具；激活的工具用朱砂色，其余墨色 |
| 选区浮层 | 见 3.4 | 一行 |

### 3.3 合并与下沉

- **视图面板（Aa）**：缩放、适宽、单页/连续滚动、纸色（宣纸/素白/夜读）、亮度。原来的缩放、适宽、刷新全部收进来。
- **翻页**：用键盘（← →、PgUp PgDn）、滚动和页码胶囊，不再常驻上一页/下一页按钮。
- **导出菜单**：把"引用与导出"和"导出札记"合并为一个入口，内部分两组
  - 引用格式：GB/T 7714、APA、BibTeX
  - 札记导出：Markdown、带原文引文的 Markdown
- **撤销/重做**：只在工具坞里，同时保留 Ctrl/⌘+Z、Shift+Ctrl/⌘+Z。
- **更多（⋯）**：文档信息、打印、重新加载、快捷键一览。

### 3.4 选区浮层（一行）

```
 ● ● ● ● │ U │ ✐ 批注 │ 复制 │ ⋯
 黄 绿 蓝 红   下划线
```

- 四个颜色点内置，**点一下即高亮**，不再先点"高亮"再选色。
- "复制引文、存为摘录、粘贴为批注、翻译"放进 ⋯。
- 字数提示缩为浮层右上角小角标，不占一行。
- 出现位置：默认在选区**上方**；上方空间不足翻到下方；**不得压住选区本身**（距选区 8px）。滚动时自动消失，停下后不自动再现，需重新选择。
- 取消：Esc、点击空白处、选区消失。

### 3.5 补充的读者功能

| 功能 | 入口 | 说明 |
|---|---|---|
| 目录 / 缩略图 / 书签 | 左侧抽屉（按 L） | 三个页签，书签用朱砂色小旗 |
| 全文搜索 | Ctrl/⌘+F | 命中处淡黄标记，侧边显示命中列表 |
| 阅读进度线 | 顶栏底部 | 2px 朱砂色，随阅读位置推进 |
| 专注模式 | 按 F | 隐藏顶栏、工具坞和所有浮层，只留页码小胶囊 |
| 记住上次位置 | 打开文献时 | 页码胶囊中提供"回到上次读到的地方" |

### 3.6 图标与样式规范

- 线性图标，线宽 1.5px，统一圆角。
- 默认墨色（#2b2b2b 左右）；悬停显示文字标签与快捷键；激活态用朱砂色。
- 不给按钮加底色块、不加边框；分组之间用 1px 淡线或 12px 间距。
- 夜读模式下：图标改为浅米色，朱砂色提亮约 15%。

## 四、方案二：页码胶囊

### 4.1 常态

平时只是文字"第 2 页 / 8"，**无边框、无底色**。滚动时同样位置在页面底部有一枚半透明小胶囊同步显示，停下 1.5 秒后淡出。

### 4.2 点击展开

```
        ┌────────────────────────────────────┐
        │  跳转到  [ 2 ]  / 8      刊印页码 190 │
        │  ─────●───────────────────────────  │
        │   ▏▏▏·▏▏▏▏▏▏▏  （· 为有批注的页）      │
        │  ┌──┐                                │
        │  │缩│  第2页 · 引言                  │
        │  │略│                                │
        │  └──┘                                │
        │  目录   书签   回到上次读到的地方      │
        └────────────────────────────────────┘
```

| 能力 | 规则 |
|---|---|
| 输入框 | 展开即自动全选；回车跳转；↑↓ 加减 1 页 |
| 相对跳转 | 支持 `+3`、`-2` |
| 刊印页码 | 支持输入期刊原页码跳转（如论文页眉印的 190、191）；显示为"第 2 页 · 刊印 190" |
| 拖动条 | 拖动时实时预览目标页缩略图；条上用朱点标出有批注的页 |
| 章节 / 书签 | 点击跳转，当前章节高亮 |
| 关闭 | Esc、点击外部、跳转后自动收起 |

### 4.3 刊印页码映射

- 数据：`pageLabels: { 1: "189", 2: "190", ... }`，可自动读取 PDF 的 PageLabels，读不到时允许在文献信息里手填起始页码。
- 引用与导出一律使用刊印页码，PDF 序号只作内部定位。
- 批注和札记里同时记录两种页码，显示以刊印页码为主。

## 五、方案三：朱批（页边批注 + 札记回顾）

### 5.1 核心思路

把原来混在一起的两件事拆开：

| | 页边朱批（记录） | 札记（回顾） |
|---|---|---|
| 目的 | 读到哪、想到哪、当场写下 | 总览、检索、整理、导出 |
| 位置 | 页面右侧边距，与被批句子同高 | 右侧栏，顶栏"札记"按钮切换 |
| 特点 | 轻、快、自动保存 | 全、可筛选、可搜索 |

### 5.2 页边朱批：版面

```
┌──────────────────────────┬───────────────┐
│                          │               │
│   这是被选中的一句话 ─────┼─ ┌─────────┐ │
│   ▔▔▔▔▔▔▔▔▔▔▔▔▔▔         │  │ 朱批    │ │
│   后文正文继续……          │  │ 这里和… │ │
│                          │  └─────────┘ │
│   页面整体向左平移       │  260px 边距  │
└──────────────────────────┴───────────────┘
```

- **推开而不是覆盖。** 页面整体向左平移约 260px，边距只在"有批注"或"正在编辑"时才让出来。
- **同高对齐。** 批注卡片与被选句子的首行同高；多条批注垂直方向冲突时自动错开，并用细线连回原文。
- **连接线。** 被批注文字下方为朱砂细下划线，卡片与原文之间一条 0.5px 朱线或括号，不加粗。
- **收起态。** 边距里只有一枚朱点；悬停预览前两行，点击展开编辑。

### 5.3 写批注的流程（目标：不超过 2 步）

1. 选中文字 → 点浮层里的"批注"，或直接按 **Enter**。
2. 页边出现输入框，**光标已在里面**，直接打字。

之后：

- **自动保存**，不设"保存"按钮；失焦或停止输入 0.8 秒后写入。
- **空内容自动丢弃**，不留垃圾批注。
- **Esc 或点击空白处**收起；Ctrl/⌘+Enter 收起并保留焦点在正文。
- **高亮与批注合一**：写了批注，对应文字自动高亮（默认黄色，可改色）。
- 笔记字体：默认朱色楷体，呼应"朱批"；提供"换为宋体/黑体"开关，长笔记看着不累。

### 5.4 无选区速记

| 动作 | 方式 | 结果 |
|---|---|---|
| 页批 | 按 N | 给当前页写一条不关联具体文字的批注 |
| 速记条 | 底部单行输入条（可选） | 回车即存，归入当前页 |
| 一键标签 | 输入框上方四个小标签 | `？`疑问、`！`要点、`★`引用、`◆`方法，点一下加前缀 |

### 5.5 窄屏与无空间情形（解决"遮挡"的最终防线）

当窗口宽度不足以让出 260px 边距，或页面已适宽占满（如图1）：

- 改为**底部半屏抽屉**（高度约 40%）。
- 同时把被批注的那一行**自动滚动到可视区上三分之一**，文献与输入框同时可见。
- 抽屉关闭后，滚动位置恢复到打开前（带 200ms 过渡）。

### 5.6 札记：回顾与整理

- 右侧栏，名称统一为"札记"，**不再承担写批注**。
- 内容：按页分组的批注列表；顶部筛选（颜色、标签、仅批注/仅高亮）；搜索框。
- 点击某条 → 原文跳转并闪烁高亮 1 秒。
- 单条操作：编辑（回到页边）、删除（带撤销条）、复制为引文。
- 顶栏"札记"按钮在三种状态间循环：**页边（默认）→ 侧栏总览 → 全部隐藏**。

### 5.7 键盘全流程

| 键 | 作用 |
|---|---|
| Enter | 对选区写批注 |
| N | 写当前页批注 |
| Esc | 收起批注/浮层 |
| Ctrl/⌘+Enter | 收起并回到正文 |
| J / K | 在批注之间上下跳转 |
| L | 打开左侧目录/书签 |
| F | 专注模式 |
| T | 展开/收起工具坞 |
| Ctrl/⌘+F | 搜索 |
| Ctrl/⌘+Z | 撤销 |

## 六、数据与实现要点

### 6.1 批注数据结构（建议）

```json
{
  "id": "a_20261031_001",
  "docId": "...",
  "page": 2,
  "pageLabel": "190",
  "type": "note",
  "color": "yellow",
  "tag": "！",
  "quote": "被选中的原文文字",
  "quoteContext": { "prefix": "前文20字", "suffix": "后文20字" },
  "rects": [{ "x": 0.12, "y": 0.34, "w": 0.55, "h": 0.02 }],
  "text": "批注内容",
  "createdAt": "2026-10-31T11:30:00+08:00",
  "updatedAt": "2026-10-31T11:32:00+08:00"
}
```

### 6.2 锚点策略

- **双锚点**：文字引文（含前后文）＋ 页内归一化坐标（0–1）。缩放、重排、换设备后，优先用文字匹配，匹配失败再回退到坐标。
- 无法匹配时，在札记里标"位置可能已偏移"，不静默丢弃。

### 6.3 性能

- 页边布局只对**可见页及相邻 1 页**计算；其余页只存数据。
- 批注卡片避让使用单次布局计算，滚动中用 transform 平移，不重复测量。
- 缩放过程中暂时隐藏页边卡片，缩放结束后一次性重排。

### 6.4 文案统一表

| 现有 | 统一为 |
|---|---|
| Margin Notes · Page 13 | 朱批 · 第 13 页（刊印 190） |
| View in Notes | 在札记中查看 |
| Delete | 删除 |
| Highlight / Annotate | 高亮 / 批注 |
| Export | 导出 |

## 七、实施顺序

| 阶段 | 内容 | 预期效果 | 难度 |
|---|---|---|---|
| **第一期** | 合并两条工具栏为单顶栏；选区浮层瘦身并内置颜色；页码胶囊（展开输入 + 刊印页码）；文案统一 | 立刻释放约 100px 阅读空间，视觉干净 | 低 |
| **第二期** | 页边朱批（推开布局）；窄屏底部抽屉与滚动避让；自动保存与空批注丢弃；Enter/N 快捷键 | 解决遮挡与"不随手"两个核心问题 | 中 |
| **第三期** | 札记总览栏；带批注刻度的拖动条与缩略图；视图面板；左侧目录/书签；专注模式；搜索 | 补齐常见阅读器能力 | 中高 |

## 八、验收标准

1. 任何批注、浮层、面板都**不遮挡被引用的文字**（用图1的场景实测：选中小节标题后写批注，标题与上下文仍可见）。
2. 从选中文字到敲出第一个字，**不超过 2 步操作**。
3. 全程可以只用键盘完成（选区 → 批注 → 收起 → 跳转到下一条）。
4. 界面文案**全部为中文**，无中英混排的按钮和标题。
5. 顶部固定区域高度 ≤ 50px，且滚动时可隐藏。
6. 缩放、窗口大小变化后，批注位置不漂移（抽查 5 条）。
7. 200 页文献连续滚动，页边批注不出现明显卡顿（帧率不低于 50fps）。

## 九、风险与取舍

| 风险 | 应对 |
|---|---|
| 页面平移 260px 后，正文被挤出屏幕 | 空间不足时自动转为底部抽屉；允许用户在设置里固定为"抽屉模式" |
| 批注过多导致边距拥挤 | 超过 4 条同屏时折叠为朱点列表，点击逐条展开 |
| 朱色楷体长文不易读 | 提供字体切换，默认只对前 200 字用楷体 |
| 刊印页码读取不到 | 允许手填起始页码，缺省时只显示 PDF 页序 |
| 工具坞收起后用户找不到 | 首次使用时做一次轻提示；顶栏"更多"里保留入口 |
