## 阅读工具

主顶栏保持 60px 和适度标题字号；第二层 42px 工具条按用途分组：

- 选择文字、高亮模式、批注；高亮模式拖选即保存，Esc 返回选择。
- 撤销、重做。
- 引用与导出，直接打开既有五种 CSL 格式；导出当前文献札记。
- 缩小、适宽、放大、旋转。
- 上一页、下一页。

选区面板明确显示“所选原文 / 译文”和字符数。第一行是复制、高亮与颜色、批注、翻译；第二行是复制引文、存为摘录、粘贴为批注。复制引文包含选文、页码和当前样式的参考文献条目。浮层按真实尺寸避让选区，窗口缩小时重新定位。

粘贴只写入批注，不改写 PDF。连续高亮保存完成时不会清除后一次选区。批注的版本绑定、自动保存、撤销重做及原件引用规则继续沿用。

工具组织参考 [Zotero 阅读器说明](https://www.zotero.org/support/pdf_reader) 与 [Acrobat 批注工具说明](https://helpx.adobe.com/acrobat/using/mark-text-edits.html)，采用分组和选区上下文的方式，功能按本应用的只读文献工作流实现。

## 三个独立的数据页面

- **日课 / Journal**：阅读时长、可提取字数、访问页、阅读文献；阅读时长或页面访问趋势；热力图；文献明细。
- **志趣 / Themes**：话题和已确认领域排行，可按文献数或阅读时长查看；下方保留分类与明细。
- **用度 / Ledger**：输入/输出 Token 与未知请求；回传 Token 趋势；模型用量排行；成功/失败/取消比例；原有明细、活动和存量统计。

新增六个图表框，保留原阅读热力图。图表支持数值查看和数据表；趋势支持键盘方向键。没有真实记录时显示空态，测试合成数据不会被注入日常文库。话题可以多重归属，篇数不相加；Token 缺失保留为空白，不冒充为零或实际费用。服务端回传的用量与文字估算继续分开。

## 兼容与交付

schema 保持 6，本轮没有数据库迁移或新增依赖。本地与 Zotero 文件仍关联原件，下载全文保存一份。窗口红黄绿控件仍由原生系统标题栏承载，应用内不绘制仿制控件。升级前退出旧版，避免同时打开同一文库。

预览适用于 macOS Apple Silicon，使用本地 ad-hoc 签名，尚未公证。源码包附构建、测试、资源、英文指南及验收证据，不含用户文库、密钥或个人原件。

## 最终验收结果

86 项数据与单元测试、类型检查和生产构建通过；10 组原生桌面回归全部通过。新专项覆盖中英文 900/1280 宽度、三个独立小传页面、六个图表框与热力图、指标切换、键盘查看数值、菜单脱离侧栏且不超窗口、滚动到底、复制引文、摘录保存、连续高亮、粘贴批注与自动保存、引用样式、札记导出、缩放翻页和原件哈希。原有批注、引用、文件关联、中文 PDF 与实验夹注通过回归。

打包应用与构建逐文件比对一致，本地签名校验和隔离英文冷启动通过。使用合成文献与合成阅读记录，未调用付费模型，未重新访问真实出版社；测试资料不会注入实际使用的文库。DPR 1/2/3 是 Chromium 设备参数模拟，不代表三台物理显示器。
