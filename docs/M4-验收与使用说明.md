# 笺 Jian · M4「查找与带走」验收与使用说明

日期：2026-10-29  
版本：0.4.0  
基础：M3 0.3.1，保留 DeepSeek / Google Gemini API 的 Gemma 4、自定义 API 与原有阅读功能。

## 本轮交付

M4 核心流程已实现：本地 PDF 正文索引、文献信息及摘录搜索、命中定位、DOI 查询与确认入库、元数据编辑、GB/T 7714-2015 顺序编码引用、CSL-JSON / BibTeX 元数据导出、Markdown / JSON 阅读成果导出。

界面沿用纸墨色、衬线标题和文字操作。搜索范围放在输入框下方，不添加独立仪表盘；结果按文献分组，显示正文/摘录来源和 PDF 页码，默认显示三处命中，可展开。编辑和导出使用可滚动内容区，主要操作固定在底部，窄栏中的详情按钮可换行。

## 使用步骤

### 搜索与定位

1. 打开文库或导入 PDF 后，应用在独立的隐藏沙箱窗口中用已打包 PDF.js 抽取文字，逐页保存本地索引。不会发送到模型服务。
2. 搜索框可切换「全部 / 文献 / 正文 / 摘录」；文献信息包含题名、责任者、日期、字段和标签。摘录包含已保存的原文、译文与评论；临时翻译缓存不进入搜索。
3. 点击正文结果会打开对应文档版本、跳到对应 PDF 页并标出命中所在的文字片段区域；点击摘录结果还会显示摘录面板。标记按 PDF 文本片段定位，并非逐字排印重建。
4. 文库全局搜索快捷键为 `⌘⇧F`；阅读器 `⌘F` 打开「查找本文」。Windows/Linux 的相应入口也接受 Ctrl。
5. 索引状态行可「暂停」或「更新索引」。页级检查点会保留，重启后从缺失页继续；失败文件有原因，点击更新可重试。已有索引页可先搜索。
6. 两字及一字短查询按最多 800 个候选来源分批查找，出现「继续查找更多结果」时可继续，不能将第一批无命中解释为全库不存在。较长查询走 SQLite FTS5 trigram，单批最多 300 个候选来源和 80 个命中。

查询采用分词后 AND 组合，不向用户开放原始 FTS 语法。引号、括号、星号等输入不会被当作可执行查询语法。规范化支持大小写、去变音符、兼容字符及轻量英文词尾归并；不是通用多语言词干引擎。词组可以在同一页的不同位置分别命中，不代表严格的连续短语搜索。

### DOI 与文献信息

1. 点击「通过 DOI 添加」，输入 DOI 或 doi.org 链接。
2. 点击查询，仅将 DOI 发往 Crossref；不发送 PDF、笔记或完整文库信息。
3. 预览题名、类型、日期、语言、个人/机构责任者、期刊/会议/书名等信息，可以修改后再确认。查询成功本身不新增条目。
4. 如已有规范化相同 DOI，界面提供「打开已有」与明确的「保留为独立条目」，默认不合并或重复新增。
5. 查询未收录或无法联网时，可以手动填写，不影响已有 PDF 本地导入和阅读。
6. 详情的「编辑信息」可修改元数据。未显示的原有字段保留；Crossref 原始响应、来源与取得时间保存在条目字段中。

本轮 DOI 服务为 Crossref，不包含 DataCite、arXiv、PMID 联合检索，也不下载出版社 PDF。语言未知时保留未知，不通过题名文字外观猜测。未知外部类型映射为其他并保留源类型。

### 引用与导出

文献详情可「复制引用」或打开「引用与导出」。列表左侧的勾选框在悬停、键盘聚焦或勾选后显示，可选择多篇，再点击搜索范围旁的「导出」。

| 内容 | 格式 | 保存的范围 |
|---|---|---|
| 参考文献 | UTF-8 TXT / 剪贴板 | GB/T 7714-2015 顺序编码，按本次选择顺序编号 |
| 文献交换 | CSL-JSON | 类型、题名、author/editor/translator、日期精度、语言、期刊/书名/会议名、卷期页、出版信息、DOI/URL、ISBN/ISSN 等已支持字段 |
| 文献交换 | BibTeX | 类型映射、题名、作者/编者、年份/月份、容器题名、卷期页、出版机构、DOI/URL、ISBN/ISSN 等；机构名称保留花括号保护 |
| 阅读成果 | Markdown | 文献题名、责任者、日期、DOI、原文、已保存译文、评论、PDF 页码、文献/文档版本/摘录身份 |
| 阅读成果 | JSON（`jian-reading/1`） | 文献信息与摘录、已保存译文、评论、逐页坐标锚点、来源身份、摘录创建时间 |

导出先显示预览、字段不足提示与格式边界，再由系统保存对话框选择位置。取消保存不会创建文件。文件以 UTF-8 写入，通过同目录临时文件再替换目标。

CSL 引用使用 citeproc-js 2.4.63 与固定快照的官方 CSL 样式、中英 locale；没有手工拼装后宣称完整 CSL。界面可展开查看处理器、样式、locale、映射版本与资源哈希。2015 在这里明确指该年份样式，不代表“当前最新版标准”。未记录作者或日期时会提示补全，并按现有信息生成结果。

BibTeX 与 CSL-JSON 是支持字段的交换，不等于文库备份。BibTeX 不包含译文、摘录、集合、阅读位置、来源关联或任务，也不保证任意目标工具采用完全相同的字段解释。未指定学位类型的 thesis 不会擅自导出成博士论文。需要保留整个文库时仍使用完整备份。

## 数据升级与代码

数据库 schema 从 v2 升级到 v3，新增正文/元数据/摘录检索来源、FTS、脏标记与文档索引状态表。数据服务继续是唯一 SQLite 写入方。升级旧文库前，使用 SQLite `VACUUM INTO` 生成含已提交 WAL 内容的一致快照，保存在文库 `migration-snapshots/`。它是升级前数据库副本；完整附件保护仍使用完整备份。

不要用旧 M3 程序直接打开已升级的 v3 文库；旧版本会拒绝高于自身支持版本的数据库。

| 模块 | 作用 |
|---|---|
| `src/shared/m4.ts` | M4 API、搜索结果、抽取页、导出与元数据契约 |
| `src/shared/search-text.ts` / `page-text.ts` / `anchors.ts` | 规范化与偏移回映、PDF 碎片拼接、旧锚点兼容 |
| `src/data-service/m4.ts` | 本地检索、页级检查点、元数据写入与重复判断 |
| `src/main/m4/indexer.ts` | 独立沙箱抽取窗口、文档 token、生命周期 |
| `src/main/m4/doi.ts` | 受控 Crossref 查询、大小/超时/返回校验与映射 |
| `src/main/m4/exports.ts` | CSL、BibTeX、阅读成果与实际 CSL 引用处理 |
| `src/main/m4/ipc.ts` | 具名调用、安全边界、保存对话框与异步剪贴板 |
| `src/renderer/src/m4/` | 搜索结果、本文查找、DOI/编辑、导出、后台抽取 |
| `resources/csl/`、`resources/licenses/`、`THIRD_PARTY.md` | 样式与 locale 固定快照、哈希、许可、署名和处理器原始代码 |

## 已知边界与后续

- 正文索引支持已导入且可读取的文本 PDF；扫描件不产生可搜索正文，未提供 OCR。受密码保护文件会明确报告未纳入本轮后台索引，尚未提供密码输入与会话解锁流程。损坏编码、复杂表格、竖排、跨行断词和所有语言的词形变化不保证恢复。
- 已验证普通与旋转合成样本，不等于已对复杂真实论文或上万篇文库完成性能、内存及定位准确率认证。没有数据库硬中断式超时保证，当前通过分批、候选数与结果数限制控制查询工作量。
- 同一页每个查询 token 显示首个可映射命中；同页重复出现不会全部列成独立结果。正文框按 PDF 提供的文字片段标记，个别片段可能覆盖完整一行。
- 已存到译文缓存但未明确保存为摘录的机器译文不搜索、不作为阅读成果导出。
- 查询与导出支持范围以本文件表格为准；未实现 RIS、任意 CSL 样式安装、Word 插件、引文管理器和无损 Zotero 往返。
- 正式安装包的签名、公证、发布配置和连续真实阅读打磨属于下一阶段 M5；本交付是开发代码包及预构建产物。

本轮工作在交接包的独立副本中完成，没有覆盖原项目目录或更改真实 Zotero 文库。
