# Glossleaf 1.1.x 更新日志

记录范围：2026 年 11 月 7 日 15:00 至 11 月 8 日 14:20（北京时间）。时间以各交付包的生成时间为准。

基线为 1.0.26。1.1.0 是双平台公测包，1.1.1 至 1.1.7 为后续预览版本；当前最新为 **1.1.7**，下载见 [Releases](https://github.com/krisliu0725/Glossleaf/releases)。

---

## 11 月 8 日

### 10:55 · v1.1.7 Windows x64 便携版

- 与 macOS 预览版共用 v1.1.7 源码，包含 PDF 阅读与批注写回、双栏对照、免费 Google 在线翻译、文献分组、阅读记录、自定义译文字体、AI 阅读助手及图表问答。
- 内置英文、简体中文和繁体中文 OCR。离线翻译模型可按需下载，使用 Windows x64 CPU 运行组件。压缩包内附运行说明，干净环境首次启动为空文库。
- 154 项自动测试通过。使用解压包内的应用代码验证了首次导入、翻译流程、AI 流式问答和三种 OCR 语言。此包在 macOS 上交叉构建，尚未签名，Windows 真机启动、PDF 写回和离线推理仍待验收。

### 10:48 · v1.1.7 macOS 预览版

- 调整 AI 阅读助手的系统指令。先用一两句话回答问题，复杂问题再分段或分点。图表问答先概括主要发现，再分别解释相关子图或趋势，按图估读的数值标明约数。
- 聊天窗口支持轻量 Markdown 排版，分开显示段落、小标题和列表，重点可加粗。已有回答中的行内编号也可重新分行。

界面见 [`docs/screenshots/1.1.7/02-reader-ai.jpg`](screenshots/1.1.7/02-reader-ai.jpg)。

### 01:07 · v1.1.6 AI 助手发送流程

- 使用 OpenAI JavaScript SDK 处理 OpenAI 兼容接口的流式请求，沿用阅读器内的提问、回查和重试流程。
- 修复首次发送和附图提问的授权入口。发送时可直接打开确认窗口。连接未配置、密钥锁定或设置正在保存时，界面显示对应提示。

界面见 [`docs/screenshots/1.1.7/04-chart-qa.jpg`](screenshots/1.1.7/04-chart-qa.jpg)。

### 00:53 · v1.1.5 AI 连接诊断

- AI 设置新增文字和图片两种连接测试，分别显示首段响应时间与总耗时。
- 将等待过程分为图表准备、连接服务、等待模型、模型推理及接收回答。连接无响应、推理停滞和回答中途断流分别给出提示，方便区分故障发生在哪一步。

界面见 [`docs/screenshots/1.1.7/05-ai-connection.jpg`](screenshots/1.1.7/05-ai-connection.jpg)。

### 00:24 · v1.1.4 阅读工作区与设置

- 将「最近添加」「未分组」「回收站」移到左栏顶部的文献入口区，手动分组改用右键菜单。对齐中英文「藏卷／书迹」切换按钮，压缩阅读笔记区，并调整阅读工具栏布局，增加 AI 入口。
- 译文跟随原文的字重、斜体和对齐方式。可为常规、粗体、斜体和粗斜体导入本地字体。
- 优化图表放大、回看原文和加入专题的入口。可将选中的图表裁图交给支持图片输入的 AI 模型，快捷键为 macOS 的 `⌘⇧G` 或 Windows 的 `Ctrl+Shift+G`。
- 精简翻译和文档详情窗口。设置整合 AI 连接，增加头像管理、译文字体和色彩预设。书迹增加阅读记录和文库概况，并分开统计 AI 阅读、AI 翻译和机器翻译用量。

界面见 [`docs/screenshots/1.1.7/01-library.jpg`](screenshots/1.1.7/01-library.jpg)。

## 11 月 7 日

### 23:29 · v1.1.3 译文排版与中文题录

- 优化书库中的阅读标签和文献列表，突出当前阅读项和选中文献。
- 改善译文的标题字号、字重和版式。没有可靠原生文字层的页面在对照中保留原页，避免把手写或扫描误识别的结果混进正文。
- 支持从中文期刊 PDF 的可用文字中补全期刊、日期、作者、关键词和 DOI 等字段，供用户核对。真正的 CAJ 文件需配置 `caj2pdf` 转换器，提取效果取决于附件内容。

界面见 [`docs/screenshots/1.1.7/03-translation.jpg`](screenshots/1.1.7/03-translation.jpg)。

### 23:02 · v1.1.2 经典与极简界面

- 保留经典纸色和衬线风格，原白蓝预设调整为黑白灰极简风格。两种风格共用操作布局。
- 缩减书库、导入按钮、顶部切换和阅读工具栏的占用。译文在正文与标题之间建立字号层级，尽量跟随原文的居中、缩进和加粗。

界面见 [`docs/screenshots/1.1.7/06-minimal-theme.jpg`](screenshots/1.1.7/06-minimal-theme.jpg)。

### 22:02 · v1.1.1 书库左栏

- 重整左栏的字号、图标、行高和选中状态。增加「最近阅读」，重新打开文献可从上次位置继续。
- 调整手动分组和按作者浏览的层次，补充窄窗口布局及阅读详情收起操作。

### 16:48 · v1.1.0 双平台公测包

- 打包 Apple 芯片 macOS 和 Windows 11 x64 应用及使用说明。新用户从空文库开始，已有用户升级时继续读取系统用户目录中的文库与设置。
- 简化书库与阅读页切换，收起窄窗口中重复的 AI 入口。内置离线全文翻译可同时处理两段，保留已译缓存，暂停后继续剩余段落。
- 在 Apple 芯片 Mac 上验证 PDF 导入、扫描页检索、批注、备份、跨栏对读和真实离线翻译。Windows 包完成文件校验与包内资源检查。

## 1.1.x 之前的尾段（供参考）

- **v1.0.26**：Windows 内置英文、简体和繁体 OCR；增加离线模型的应用内安装、暂停续传、校验和移除，Windows 使用 CPU 运行组件与 Index-Translate-2B 模型，需要 Microsoft Visual C++ x64 运行库。
- **v1.0.25**：首个 Windows x64 预览包，免安装，普通导入关联原 PDF。
- **v1.0.24**：分组管理与公式保留。删除分组会解除归属并保留文献、原 PDF 与笔记。
- **v1.0.23**：对读版式与翻译进度。移除底部常驻的模型名和已译页数，保留有任务时的进度、暂停、继续、重试和取消入口。
