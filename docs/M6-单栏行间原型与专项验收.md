# M6 · 单栏行间对照原型与专项验收

日期：2026-10-29。状态：**可运行实验原型，尚未通过正式 V1.1 发布门槛**。

## 使用方式

打开 PDF，点击阅读器顶部「行间 · 实验」。原型逐页检查适配条件；可靠单栏文字页在原段落之后插入译文。点击页边「译」只翻译该段，或用顶部「翻译本页」。译文可以原生选择、复制、重译和保存为摘录。

包含图片/矢量图形、旋转文字、旋转页、明显双栏、段落区域重叠、段落置信度不足、嵌套标记文本层或文字穿过切线的页面，逐页显示说明并交由稳定原页渲染器显示。可随时切回「原文 / 双语」；复杂页仍可在双语面板翻译。行间模式不自动发送文字。

实验模式不会作为默认模式恢复；重启恢复稳定双语视图与原文位置。后台翻译任务沿用 M3 调度与缓存，没有独立生成第二套翻译请求。

## 实现契约

- 独立 `InlinePdfPage` 适配器，原 `PdfPage` 保留；两者仅共享选区收集器，使跨页或跨降级页的选区仍保存每页锚点。
- 在 PDF.js 规范 viewport 内建立全宽源 bands。从页面顶端到末端连续覆盖，无遗漏、重叠或丢弃的源行；边距也属于源分区。任意分区冲突导致整页降级。
- 每个 band 同时保留源矩形、目标矩形、band 身份和插入高度。坐标反算只允许位于该 band 原文范围的点；译文空间不会反算成伪 PDF 锚点。矩形跨片段时拆分映射。
- PDF.js 源画布完整渲染后按像素行切片，每个源像素行仅复制一次。译文高度只改变 DOM 布局，不创建无限长合成画布，也不因逐块文本流更新而重绘源图像。
- 使用 PDF.js 原生 TextLayer 字体和矩阵；源 span 只分配一次，没有复制多份全文。局部和跨段选区保留用户的真实起止偏移，保存摘录时仅从实际选中的原文范围生成锚点；译文单独可选。操作按钮不进入复制文本。
- 原有链接、保存高亮、活动段落和搜索命中使用同一个二维 band 变换。持久标注仍保存 PDF 用户空间坐标。
- 单页源缓冲加全部切片的像素预算为 **48 MiB**，有效 DPR 上限 2；高分辨率页面降低采样倍率，CSS 几何不变。退出可见范围后释放切片画布。译文不消耗画布像素预算。该值是单页预算，不是应用总内存承诺。
- 插入 ResizeObserver 测量真实译文高度。布局变化前记录「源页＋源点＋视口偏移」，变化后恢复相同源点；缩放和模式切换同样沿用源点定位。同页滚动也有延迟检查点，不依赖切页才保存。

## 正式发布前仍需完成

1. 更大的真实单栏论文集与不同字体、脚注、公式、链接、透明叠加等样本，测量接受页/降级页的精度及原文完整性。
2. 页内命名 destination、Fit/FitH/XYZ 等目的位置、长链接跨 band 的完整交互专项；当前内部链接仍沿用稳定阅读器的页级导航。
3. 更多搜索词、跨页、多矩形搜索命中的交互矩阵，以及原文/译文混合选区在不同平台的剪贴板行为。原型未接管原生复制以拼凑未选中的全文。
4. 180°/270°、不同系统 DPR、连续缩放手势、快速切文献、超长文档压力和总内存峰值测试；现阶段相应旋转页直接降级。
5. 跨页高亮在所有缩放、降级页混排下的视觉误差矩阵，以及超过本轮单一源点检查的重启恢复测试矩阵。

因此，本轮交付满足「独立适配器＋可运行单栏原型＋专项验证」，**不将 DESIGN.md §12.7 全部门槛标为完成**。稳定原文和并排双语继续作为默认交付路径。

## 工具栏与夜读末轮复核

对截图中右侧状态截断与夜读译文底色进行了专项修复：工具栏将说明、操作和状态分配到明确网格，状态单独占整行；所有界面表面均使用现有主题 token，不再使用不存在的 `--bg-subtle` 或固定浅色 fallback。页边「译」为 28 × 32 CSS px，常态、活动态与悬停态使用主题背景。

最终构建在 `work/m6-ui-final/` 的四组真实界面检查均通过：1280 × 782 和 960 × 760 内容窗口，在浅/深主题下应用根宽度均等于视口宽度；工具栏无横向或纵向裁切，所有按钮与状态在视口内，按钮互不交叠。浅色译文/页边活动入口对比度分别为 14.88:1 / 13.59:1，深色分别为 14.12:1 / 11.55:1。该结果覆盖本轮实际字体、主题和尺寸，不代替全部交互状态或平台的可用性研究。

已人工查看普通浅色和窄窗深色截图。最终用户展示建议使用该目录中的 `m6-inline.png`、`m6-inline-narrow.png`、`m6-inline-dark.png`、`m6-inline-dark-narrow.png`；原文 PDF 仍保留其白色页面，夜读只改变应用控件与译文表面。原有像素、长译文、选区/搜索、高亮和重载恢复断言也在这轮通过。
