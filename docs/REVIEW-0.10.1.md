# Glossleaf 0.10.1：阅读页融合与操作审阅

2026-10-31。基线 0.10.0；按已确认的融合设计实施。源码、macOS arm64 本地预览应用及交接资料独立归档，0.10.0 保留。

## 这次实际改了什么

- 阅读页恢复书府的 60px 品牌顶栏、相同操作区位置和中英文衬线字体。文献标题适度放大、单行省略。导出、书府／小传和设置各有固定位置；不再在滚动时自动藏顶栏。
- 顶栏下的轻工具带只常驻 PDF 页码、原文／对读、缩放、札记和更多。取消底部工具坞。选择模式、连续标注模式、撤销／重做、目录、查找、视图、打印和全文翻译放在更多菜单。
- 删除“刊印”标签、起始刊印页设置、相对页码语法及多余的页码导航面板。阅读和札记导航统一用 PDF 页序。已有 PDF PageLabels／文献出版页码仍保留在引用和导出元数据中，不重写旧记录。
- 保留四色、下划线、朱色批注、复制的选区轻工具条。点击更多直接展开同一面板；在选区上右键复用它，源文和译文不会另叠一层重复菜单。识别修正留在最后的次级入口。面板整体避让选区；无空间时占用独立布局空间，而非盖在正文上。
- 札记改成明确的开关；朱批编辑和札记回顾共用右侧 324px 区域（较窄桌面窗口 286px）。窄窗口写作采用底部抽屉。保留自动保存、冲突提示、撤销恢复和原文定位。朱批标记恢复为淡色评论图形，不再使用难以识别的小点。
- 阅读打开时保留书府的列表实例、筛选和滚动状态；隐藏的书府不再抢占阅读内快捷键。

## 卡顿和跳动的处理

原先页边栏会按当前页附近是否有批注改变宽度，宽度又直接参与每页绘制比例；本版移除这种自动布局。打开札记不重设倍率，手动缩放保持不变；显式“适宽”才重新计算。窗口调整在停止后合并处理，舒适宽度上限 840px。

滚动计算按帧合并，以二分查找定位当前页；段落同步仅检查当前页。进度条直接更新，不再为每次滚动刷新整棵阅读树。PDF 页组件复用稳定回调和每页数据，未变化的页不因父级状态变化而反复更新。保留按需文本提取、画布虚拟化和新画布就绪前保留旧画面的机制。

200 页／200 批注的同机合成对照：0.10.0 约 58.65fps，0.10.1 约 59.92fps；95 分位帧间隔分别约 17.5ms／17.6ms。两者本来都接近刷新率上限，这些数字不支持宣称“所有文档显著提速”。本次更明确的改进是减少无谓计算、避免顶栏和侧栏引起的布局变化，并保持手动缩放。另检查了用户截图中 13 页实际中文论文的关联读取和交互，并以原生滚轮事件测得约 59.59fps、95 分位帧间隔约 17.1ms；测试只代表该文件和当前设备，原件哈希未改变。

## 已验证的操作

- 93 项底层测试、类型检查、生产构建。
- 中文／英文、浅色／深色、1360px／900px 窗口；与书府顶栏高度、品牌位置和操作区位置一致。
- 左右键统一选区面板、复制、带引用复制、下划线、撤销／重做、批注自动保存、关闭后阅读位置恢复。
- 开关札记前后绘制比例一致；手动缩放不被侧栏覆盖；窄窗口编辑器不遮正文。
- 普通页码跳转、无效输入、目录／缩略图／书签、单页／连续、键盘翻页、专注模式。
- Markdown 导出及五种引用格式；翻译流式显示、复制译文、搜索命中定位（仅本机模拟服务，无付费模型请求）。
- 保存中删除不会让批注复活；版本冲突保留用户输入。
- 0°／90°／180°／270° × 50%／100%／200%／400% 高亮坐标，DPR 2，误差小于 1 设备像素；跨页一个记录、分栏矩形分离；扫描页可写页批但不自动生成空批注。
- 实验夹注原文像素一致、插入后选区／点批映射及重启位置恢复。
- 本地应用包冷启动、构建文件一致性和签名校验。详见 evidence-0.10.1/verification.json。

## 尚未跑通或本轮没有覆盖的范围

1. 扫描 PDF 的 OCR 尚未提供；可以阅读图像原页、加页批，不能把扫描文字当作可选文本。
2. 真实云模型和外部元数据服务没有用个人凭据做在线验收；本轮服务测试使用本机模拟接口。服务商模型实际可用性、限额与付费结果仍以用户配置为准。
3. 任意大型扫描件、复杂嵌入字体、所有硬件上的性能没有穷尽验证。实际论文中 PDF.js 有原文件字体名相关警告，已查看页面能显示；未修改原件字体和内容。
4. 实验夹注保持实验状态，复杂或不支持的页面沿用原版回退；本轮未扩大支持类型。
5. 本地预览应用是 arm64、ad-hoc 签名；未提供 Developer ID 公证、Windows／Linux 安装包或自动更新。

## 使用与数据

直接打开 delivery/Glossleaf-0.10.1.app。使用原有文库和配置；本版没有新增数据库版本或修改 API 协议。测试只使用临时文库，真实论文仅关联读取；交接包不含个人文库、原论文或 API Key。阅读的“页码”只指 PDF 页序；引用中的出版页码属于文献数据，两者用途独立。
