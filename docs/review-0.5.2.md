# 笺 0.5.2 · 0.5.1 审查与文库 UI 优化

日期：2026-10-29。基线：用户提供的 `jian-handoff-20261029-v0.5.1.zip`。压缩包与原工程源码逐文件一致；本轮在独立副本中修改，原 0.5.1 与用户文库未被改写。数据库继续为 schema v4。

## 文库中栏：把空间还给文献

0.5.1 的中栏顶部依次放置标题、搜索与导入、四个检索范围及 DOI/导出、索引状态，四层常驻区域挤压文献列表。本轮改为两层紧凑控件：

- 第一层保留当前集合/列表名称、篇数、导入文件和“更多”。勾选文献后，直接显示批量导出。
- 第二层为 34 px 的统一搜索框，内部整合放大镜、输入、清空、快捷键提示和检索范围。全部 / 文献 / 正文 / 摘录通过小型下拉切换，不再独占一行。
- DOI 添加、文献导出和全文索引管理收进“更多”；单篇详情中的引用与导出仍保留。
- 索引压缩为列表底部的轻量状态条，点击查看完整进度、错误和暂停/更新操作，不在顶部常驻管理按钮。
- Escape 清空输入并回到列表，清空按钮保持搜索焦点；中文输入法组合期间不发出中间查询。
- 菜单支持外部点击、焦点移出和 Escape 关闭。打开 DOI 弹窗前把焦点交回“更多”，关闭弹窗可正确恢复焦点。

### 实测空间

使用同一组 13 篇隔离合成文献和 1 个 PDF，在 1280 × 820 及 900 × 720 窗口测量：

| 项目 | 0.5.1 | 0.5.2 |
| --- | ---: | ---: |
| 中栏顶部常驻高度 | 183 CSS px | 89 CSS px |
| 1280 窗口的列表可视高度 | 544 CSS px | 611 CSS px |
| 900 窗口的列表可视高度 | 481 CSS px | 548 CSS px |
| 页面与标题栏横向溢出 | 无 | 无 |

顶部减少 94 px，约 **51.4%**。计入新增底部状态条后，测试窗口的文献列表仍增加约 67 px，相当于多容纳约一行文献。具体高度受平台、窗口与字体影响；不将此数值作为所有设备上的固定承诺。

## 审查中修复的问题

范围为 0.5.0 → 0.5.1 的改动及相关文库交互，不代表对全部既有代码完成安全审计。

| 优先级 | 问题与影响 | 本轮处理 |
| --- | --- | --- |
| P1 | 总览拿当前筛选数据填充 52 周；早于筛选的数据格与真实零混淆，阅读页的“7 天”却显示 13 周。 | 保留年度画布，但明确标记范围外/未来；阅读页按实际日期跨度显示。图中总量与颜色峰值只来自可见范围，最多展示最近 53 个日历周。 |
| P1 | 手动确认的话题不进入检索索引，点击话题可能找不到实际已分类文献。 | 分类和索引待更新记录在同一事务保存；本地元数据检索纳入已确认话题与领域；旧版本分类首次检索时补入更新队列。 |
| P2 | “研究方向”改为单列话题后，原先已确认的领域没有展示入口。 | 恢复用户确认领域列表，继续排除集合名推断。 |
| P2 | 新增的搜索聚焦监听与原监听重复，其中一处没有弹窗保护。 | 移除重复监听，保留受弹窗保护的单一入口。 |
| P2 | 话题时长为零仍强制绘制最少 2% 的条带。 | 条带按真实比例显示，零值不生成虚构长度。 |
| P2 | 新文案“导出数据”掩盖了导出全部历史、不受当前筛选影响的事实。 | 恢复“导出完整数据”，并保留范围说明。 |
| P2 | 搜索点击的文献不在当前普通列表中时，自动选中逻辑可能把详情切回首项。 | 查询期间保留命中项选择，清空搜索后才恢复普通列表选择规则。 |

保留 0.5.1 的默认文库、文库/阅读/个人导航、标签驱动研究方向、用户本地改名、语言壳、五色 token、侧栏图标和检索命中高亮。未恢复集合参与学科或话题推断。
