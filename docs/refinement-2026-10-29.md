# 界面与信息架构调整（2026-10-29）

基于 v0.5.0 交接包，按六条反馈调整。只改呈现层与一处统计口径，未动数据服务与导入链路。

## 1. 侧栏大片空白

`dash-sidebar__footer` 原本 `margin-top:auto`，把页脚顶到最底，中间留出整块空白。
改为页脚紧跟导航（`margin-top:20px`），空白处只留一条竖向渐隐线与「笺」印记，作为版面呼吸。

## 2. 研究方向改用文献标签

`src/data-service/analytics.ts`：删除以 `collection` 为 `fields` 兜底的查询。
「研究方向」现在只由 **文献自带标签** + **用户确认分类** 组成；集合不再作为话题来源，
避免把自建文件夹名当成研究内容。页面由两列改为单列排行，每行显示 篇数 / 时长 / 比例条。

## 3. 热力图与两个雷同面板

- 柱状趋势图替换为**连续周列热力图**：一列一周、一行一日、月份标在底部，五级朱色色阶。
- 增加「每天 / 每周」切换；每周模式为单行周合计。
- 总览与阅读记录不再重复：
  - 总览 = 账户条 + 四项指标 + 整年热力图 + 研究方向前 5 + 本期间使用 + 文库现状
  - 阅读记录 = 四项指标 + 按范围展开的热力图 + 阅读过的文献表 + 逐日明细

## 4. 文库侧栏图标与交互感

- 每行加 16px 线性图标（全部/最近/集合/标签/导入/备份）。
- 分组标题上方加细分隔线；行悬停有底色；选中行左侧起一道 2px 朱线。
- 行高与左内边距统一（28px 图标槽），计数改为胶囊底。

## 5. 检索关键词高亮

原样式是 12% 朱色底，几乎看不出。改为黄底墨字 + 下缘细线 + 轻微内边距。
命中类型用颜色区分：文献信息=黄、正文=青、摘录=朱，并加圆点。

## 6. 命名与信息架构

按「用具体名词、两个字」重排：

| 位置 | 中文 | 英文 |
|---|---|---|
| 导航 | 文库 / 阅读 / 个人 | Library / Reader / Profile |
| 个人分页 | 总览 / 阅读记录 / 研究方向 / 模型用量 | Overview / Reading / Research / Usage |

- **默认页面改为文库**；个人（含统计）排在最后。
- 总览并入「个人」，新增本地账户条：用户名（可改）、「仅存本机」说明。
- 右上角语言切换（中 / EN）落在个人页标题栏。

### 五色

新增 `--ink / --vermilion / --azure / --ochre / --rice` 五个语义色。
指标卡按 朱（阅读）/ 青（字数）/ 黄（页面）/ 墨（用量）区分；标签图标用黄，选中态用朱。
