## 规格优先关系

批注 v1.2 的联动修订覆盖 UI v2.1 对应条目：右栏两个标签、三个选区入口、朱批浮层、快捷键 1–6/H/N，以及取消 PDF 原译联动的青底。小传是已有数据主页，继续保留；不会把它误改成作者视图。书页已是阅读器，不另造同名列表视图。

此前用户明确要求典雅的中文与英文字体，因此继续保留宋体与 Source Serif 4 体系，不直接采用附件中与此冲突的黑体建议。紧凑列表回到 56px 最小行高，长标题仍可展开两行；宽松列表继续可选。书府顶部保留已确认的双主页开关，与搜索、收录和设置分组排布。

Logo 使用补充包的 V3 两路径几何，不再使用 0.8.0 自制折角信纸图形。默认墨朱，20px 图形、8px 间隔，中文图形＋笺、英文图形＋Glossleaf。六配色只作用于品牌，功能语义色独立；Dock 使用固定默认墨朱，不声称跟随用户配色动态变化。

## 数据落地

schema 从 5 升至 6。沿用 annotation / entity / note / reading_state / translation_record，不要求为了与示例 SQL 同名而重建已使用的数据表。

阅读高亮与朱批正文仍在 annotation；comment 是朱批正文的唯一可编辑持久化字段。anchorsJson 保存文字/点锚和引文上下文；highlightId 仅关联，不决定朱批生存期。reading_items 为 SQL 视图，页面按关联关系组合为统一阅读成果投影；不建投影实体或冗余正文表。导入的原始载荷属于来源证据，不作为第二份可编辑朱批。

页面坐标遵循 PDF.js viewport 与未旋转页面空间的变换；点锚使用未旋转页面宽高比例。引文前后文参考 [W3C TextQuoteSelector](https://www.w3.org/TR/annotation-model/#text-quote-selector)，当前仅保存定位依据，不自动迁移到替换后的文件。PDF.js 变换依据见 [官方示例](https://mozilla.github.io/pdf.js/examples/)。

## 独立核验色谱

scripts/audit-palettes.cjs 使用 sRGB 白底叠色、D65 Lab、CIEDE2000，先验证标准参考色对 2.0425，再计算全部候选色。当前七套在 40% 下最近两色 ΔE 为 8.94–11.22；基础色与朱批色最小距离均大于 14；55% 下测试墨色正文的最低对比度约 7.39:1。

这不代表各种 PDF 自带背景、彩色字体或所有色觉缺陷都只凭颜色可辨。实际界面始终保留槽号、名称和朱批形状；PDF 默认白底，不新增反色模式。可复算结果随验收证据提供。

## 明确留在后续的范围

按批注 v1.2 既定范围，单文献色谱、语义槽名、无锚点全文札记、Word/PDF/CSV 导出、替换文件后的批注迁移确认、页边连线不进入本版。原件改动仍需新版本；不以文本相似度静默套用旧批注。没有新增 OCR、富文本编辑、AI 自动批注或协作平台。
