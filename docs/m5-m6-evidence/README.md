# 验证证据

2026-10-29。Dashboard 有数据截图来自隔离的确定性夹具，不是用户数据、账单或生产占位。空库与打包截图显示真实初始状态。交付不含测试数据库和密钥。

- dashboard / dashboard-empty：导出、分类、主题、开关、窄窗和诊断。
- ui：弹窗、焦点、集合、勾选、迟到查询、错误与窄窗。
- m6：最终深浅色和工具栏，包含同轮像素、长译文、查找、选区和重载恢复；crop / rotate 为对应专项。
- reading-activity：焦点与 idle 传感显式受控，验证渲染器心跳、弹窗、原生最小化、IPC 和数据库；不是原生抢焦点测试。
- m3 / m4：翻译、摘录、查找和导出回归。
- package：独立应用的空库与 PDF 阅读器截图。
- verification.json：本轮结果汇总。复现命令见 HANDOFF。

evidence.json 内的 UUID、路径和示例内容来自临时夹具。
