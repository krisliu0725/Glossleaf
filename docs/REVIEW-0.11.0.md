# 笺 · Glossleaf 0.11.0：阅读工作区

2026-11-01。基线 0.10.1。按最新反馈实现两端工具分组、紧凑札记和同窗口多文献标签。延续原有纸墨主题、中英文衬线字体、小圆角及淡色按键反馈。

## 阅读空间与工具

阅读区仍使用 60px 品牌顶栏和 42px 工具带，总计 102px。文献标签复用原标题区域，不新增一整行。正文外围留白从上下 28px 缩减到 18px；侧栏默认关闭，需要时明确打开。1360px 验收窗口中，札记打开时原文区域仍约占正文宽度的 76%；关闭后原文使用整个正文区域。

工具带按用途两端对齐，中间留空：

- 左侧：目录／书签、上一页／页码／下一页、选择文字、高亮、下划线、批注。
- 右侧：原文／对读、缩小／适宽或倍率／放大、旋转、视图与纸色、札记、更多。

同类工具用淡分隔线分组。图标保留可访问名称和提示；当前选择有浅底及细朱线。选中文字后点击高亮、下划线或批注直接作用于该选区；无选区时高亮／下划线进入连续标注模式，批注为当前页落批。选区浮动面板继续提供颜色、复制、引文、摘录等快捷操作。

较窄窗口把旋转和视图收进更多，保持单行；中文和英文 900px 窗口没有工具带溢出。查找、撤销／重做、专注、文档信息、打印和全文翻译继续留在更多中。

## 札记更紧凑

- 笺注、札记各占页签整行的一半，高度 42px。
- 默认仅显示条目分类和一行搜索；颜色／标记筛选通过搜索旁的小筛选按钮展开。筛选生效时按钮保持强调，可清除。
- 收紧筛选栏、页分组和卡片间距；只有一页札记时不再重复显示外层页码标题。验收中首条卡片距离页签底部约 88px。
- 札记页不再显示底部翻译服务状态；翻译页保留服务入口。
- 批注卡片保留淡框、朱色文字和原文定位。保存错误时提供复制草稿和明确放弃本次修改的恢复入口；不因标签切换静默丢弃内容。

## 同时打开多篇文献

1. 在书府打开一篇文献，得到一个阅读标签；回书府继续打开另一篇，追加标签。重复打开同一文档版本会切到已有标签。
2. 标签放在原顶栏标题位置，长标题省略并可查看完整名称。多个标签可横向滚动；当前标签自动进入可视范围。每篇有单独关闭按钮。
3. 每篇分别保存页码、缩放、旋转、原文／对读、侧栏和标注工具状态；切换时先提交批注并立即保存阅读记录，再切换。保存冲突会留在当前编辑器，保留本地草稿。
4. 关闭当前标签会切到邻近文献；关闭最后一个返回书府。书府增加一条紧凑的已打开文献入口，方便重新进入现有标签。
5. Ctrl+Tab、Ctrl+Shift+Tab、Ctrl+PageUp／PageDown 可切换文献；标签区支持左右方向键及 Home／End。普通左右键仍用于翻页。

为控制内存，仅挂载当前阅读器。离开的 PDF.js 文档会销毁 worker／绘制资源，保留的是轻量界面状态，切回后从本地原文件读取。后台整篇翻译任务继续由原任务服务管理。没有复制原 PDF，也没有更改原件关联策略。

## 验证范围

本版新增阅读工作区验收覆盖：两端位置、17 个可见工具按钮、等宽页签、紧凑札记、两篇独立状态、立即切走时提交批注、去重、关闭规则、书府返回、六篇长标题溢出、中英文 900px 窗口、保存冲突及恢复。使用隔离临时文库，无真实模型费用，无个人书库改写。

保留的引用、高亮、批注、搜索、翻译、几何定位及冷启动回归结果见 docs/evidence-0.11.0/verification.json。只有列入该文件的本版检查代表本次验收；历史 evidence 只说明对应旧版本。

## 边界

- 多文献是当前窗口内的标签切换；本轮没有增加并排 PDF 分屏或多窗口阅读。
- 完整标签清单和旋转等临时界面状态在本次窗口会话内保留。重启后仍使用已有的逐文献阅读记录，不自动恢复整套标签。
- 非活动 PDF 不继续渲染，切回需要重新加载本地原件；不承诺所有大型文件都瞬时切换。
- OCR、真实云服务凭据验收、平台安装包范围沿用既有边界。本机预览包为 macOS arm64、ad-hoc 签名，未公证。
- 数据库仍为 schema 7，无本次迁移；个人文库、API Key 和原文件没有用于改写式测试。
