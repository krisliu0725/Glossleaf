# 使用数据与 Token 计量

所有统计只写入当前本机文库的 SQLite，不向分析平台发送。默认启用；关闭后不再新增阅读、网络用量或操作记录，文库存量仍可展示。清除统计只删除计量记录，保留 PDF、摘录、笔记、术语和用户确认的话题/领域。

## 阅读

阅读器每 5 秒发送一次心跳。主进程再次确认：主窗口聚焦、可见、未最小化，系统闲置时间少于 60 秒，前端仍处于可见且活动的阅读状态。首次打开只登记访问页，时长为零；连续两次心跳才累计中间区间。间隔大于 15 秒、系统睡眠/锁屏、窗口失焦、离开阅读器或系统时钟跳变，会中断连续计时。未采样到的最后几秒不会追补，因此这是保守的活动时长代理，无法证明目光停留或内容理解。

重复心跳以采样 ID 去重。页面切换登记新的访问；连续阅读同页不反复增加页访问量。去重页数和重复页访问量分别展示。字数来自访问页在本机 PDF 索引中的可提取文本，去掉空白后按 Unicode 字符计数；词数采用“汉字逐字 + 其他语言字母/数字词串”的混合代理，含连字符的英文词作为一个词。它们都不代表实际逐字读过或已经理解。扫描件和无可提取文本的未索引页计量覆盖不足，不能用零冒充已读字数。

时长保存为 UTC 区间，查询时按所选 IANA 时区切分当地午夜，可正确处理夏令时与时区变化。7 / 30 / 90 天指查询时刻向前滚动的对应小时数；全部从本机开始统计时刻计算。

## 模型请求与 Token

每一次实际发出的 HTTP 翻译请求产生一个独立 attempt ID，同一翻译操作重试共享 operation ID。交互、后台整篇翻译、配置测试分别标识。多个订阅者共享一次请求时只记一次；本地缓存命中不生成模型 Token，只增加缓存命中操作数。取消、服务错误、响应中断也保留请求尝试；如果服务在中断前已返回真实用量，就保留这些数字。

| 协议 | 计量来源 |
| --- | --- |
| DeepSeek / OpenAI 兼容 Chat Completions | `usage.prompt_tokens`、`completion_tokens`、`total_tokens`；请求 `stream_options.include_usage=true`。缓存命中用 `prompt_tokens_details.cached_tokens` 或 `prompt_cache_hit_tokens`，推理量用 `completion_tokens_details.reasoning_tokens`。 |
| Google Gemini 原生协议，包括其托管的 Gemma | `usageMetadata.promptTokenCount`、`candidatesTokenCount`、`totalTokenCount`、`cachedContentTokenCount`、`thoughtsTokenCount`。总量采用服务返回值，避免漏计思考量。 |
| Ollama | 完成事件中的 `prompt_eval_count` 和 `eval_count`；两者均存在才相加为总量；如有 `prompt_eval_cached_count` 一并保留。 |

流式事件中的用量通常是累计值，后到事件更新已有字段，不能把所有事件相加。未返回的字段保持 `null`；真实零为 `0`。汇总旁列出返回总量的请求数和未知总量的请求数。历史译文记录不能反推出真实 Token。按字符数除以 4 的估算值独立存放，提示词与输出分别估算，不用于补足已报告值，也不用于账单。未录入服务单价，所以不展示虚构费用。

统计记录只含时间、协议、服务主机名、模型 ID、用途、完成状态、HTTP 状态、计量数字、文献/页标识；不保存 API Key、认证头、完整 URL、提示词、原文或译文。关闭后重新开启以及清空之后，之前尚未完成的请求不会在完成时把旧计量补回。

## 文库存量、活动与分类

文库存量包含既有文献、PDF、实际管理的文件字节数、索引页与状态、摘录评论笔记、保存译文、术语、缓存。管理文件字节数不包括数据库、备份或缓存磁盘空间。

期间活动只来自启用后的成功导入、搜索、创建摘录/评论、导出、缓存命中、翻译完成、任务终态和可观测错误，不会把历史存量当成本期新增。一次失败请求计作一次失败尝试，多次重试会对应多个尝试。翻译完成量对应完成的真实网络调用，不是去重文献或保存译文数。

话题/领域优先使用用户明确填写的分类。没有确认分类的文献分别采用已有标签/集合为代理，并保留来源标识；系统不根据标题擅自作学科判断。分类分布中“文献数”是当前文库存量，“阅读时长”是筛选期间该分类文献的活动时长。多标签、多集合会重叠，不能把分类时长直接相加为总阅读时长。

阅读文献明细最多返回时长最高的 100 个版本；话题/领域各最多 50 组。完整计量数据可导出 JSON。导出包含分类名称和本机文献标识，不包含文献标题或阅读内容。备份按原有整库备份规则包含本机统计；用户可在导出整库备份前清除计量。
