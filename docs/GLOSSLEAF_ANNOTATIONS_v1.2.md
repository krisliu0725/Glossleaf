## 0. 结论

**方向正确，原则写得好**："一套数据多种呈现""不改 PDF""复用现有系统""朱批即笔记、无需再保存到笔记"都应保留。

但按原文直接开发，会遇到 **4 类问题**：

| 类别 | 问题 | 严重度 |
|---|---|---|
| **A. 可用性（实测）** | 默认 30% 透明度下，七套色谱里"最像的两种颜色"色差只有 2.9–5.9（ΔE2000），正常视力下就难以分辨；红绿色盲下几乎不可能分辨（≈1）。三套色谱里的红色槽位与朱批色过近（ΔE 9–11）。 | 高 |
| **B. 与现有设计冲突** | 朱批编辑会"抢占译文栏"，打断对读；选区工具条 9 个入口；落批在阅读工具栏占一个按钮；与我们刚确定的"阅读页顶栏 6 控件""撷英/札记"命名都不一致；朱砂色值与品牌 token 不同且没有深色版本。 | 高 |
| **C. 数据与逻辑矛盾** | "每条高亮保存透明度"与"全局可调透明度"矛盾；单文献色谱覆盖、Note Source Relation、Reading Projection 对 V1.0 是过度设计；缺少撤销、改色、重叠高亮、无文本层 PDF 等关键场景。 | 中 |
| **D. 验收与范围** | 验收项几乎都没有数值；S Tier 全部塞进 V1.0，风险集中。 | 中 |

优化后的方案：**保留你的全部产品意图，把 V1.0 的交互压缩到更少的入口，并把可验证的指标写进验收**。完整规格见第 4 节，可直接替换原文交给开发 Agent。

- 朱批 = 笔记，保存即进入札记；
- 纯高亮不产生空笔记；
- 删除高亮不删朱批，反之亦然；
- 不改 PDF 文件；
- 更换色谱不改旧高亮；
- 不做独立笔记平台、不做 AI 自动批注、不做协作；
- 不允许默认布局出现四列。

## 3. 色谱实测与调整

### 3.1 方法

- 基底：白色 PDF 页面，高亮以 `mix-blend-mode: multiply`、按 sRGB 空间叠色（与浏览器行为一致）；
- 指标：CIEDE2000（ΔE），比较同一色谱内**最近的两种颜色**；
- 色觉缺陷：Machado 2009 模型（红盲 / 绿盲 / 蓝黄盲，严重度 1.0）；
- 参考：ΔE < 5 基本分不清；5–10 勉强；> 10 容易分辨。

### 3.2 原色谱的结果

| 色谱 | 30% 最近两色 ΔE | 40% | 45% | 30% 红盲 / 绿盲 | 最近朱批色 ΔE |
|---|---|---|---|---|---|
| 宋瓷 | **3.3**（槽 3-6） | 4.2 | 4.6 | 1.5 / 1.3 | 14.4（槽 3 胭脂） |
| 敦煌 | 5.9 | 7.5 | 8.2 | 1.4 / 1.2 | **11.1**（槽 1 丹砂） |
| 山林 | 4.8 | 6.2 | 7.0 | 0.4 / 1.2 | ≥ 20 |
| 绢本 | 4.7 | 5.9 | 6.5 | 0.5 / 1.1 | ≥ 20 |
| 秋山 | 5.4 | 6.8 | 7.4 | 1.2 / 0.5 | 16.2 |
| 书斋 | 4.5 | 5.7 | 6.3 | 1.8 / 1.2 | **9.3**（槽 1 朱砂） |
| 月夜 | **2.9**（槽 3-6） | 3.8 | 4.3 | 0.9 / 1.7 | ≥ 20 |

结论：

1. 基础色本身（不透明）的最小 ΔE 是 9–14，设计得没问题；**问题出在 30% 透明度把它们压扁了**；
2. 即便把透明度推到上限 45%，宋瓷与月夜仍然 < 5；
3. 红绿色盲用户基本无法靠颜色分辨六色（≈ 0.5–1.8）。六色高亮这个设计在色觉缺陷下天然受限，需要靠序号与名称补偿；
4. 正文可读性**没问题**：墨色正文在 45% 高亮上的对比度最低 8.6:1（需求 ≥ 4.5:1）；
5. 敦煌丹砂、书斋朱砂两个红色槽位与朱批色过近，会让用户把"红色高亮"和"朱批"混为一谈。

### 3.3 建议调整

1. **默认透明度 40%，范围 25–55%**（原 30% / 20–45%）；
2. 色值微调（每个颜色偏移不超过 ΔE 5.5，保持复古低饱和；调整后的最小色差在 40% 下提升到 8.9–11.2，最近朱批距离全部 ≥ 14）：

| 色谱 | 槽 1 | 槽 2 | 槽 3 | 槽 4 | 槽 5 | 槽 6 | 40% 最近两色 ΔE（原 → 新） |
|---|---|---|---|---|---|---|---|
| 宋瓷 | 天青 `#549C9A` | 缃黄 `#DEA85B` | 胭脂 `#BC6368` | 豆绿 `#939F71` | 花青 `#6B7EAA` | 赭红 `#9E887F` | 4.2 → **10.7** |
| 敦煌 | 丹砂 `#CC5F5B` | 石青 `#6A869B` | 石绿 `#739A77` | 土黄 `#BCA047` | 绛紫 `#8C6F91` | 赭石 `#B38B72` | 7.5 → **11.2** |
| 山林 | 松绿 `#5A8A73` | 苔黄 `#ADB66F` | 枫赭 `#BE745C` | 山岚 `#6C8AA0` | 紫藤 `#AC8AA4` | 枯木 `#BBA890` | 6.2 → **9.9** |
| 绢本 | 胭脂 `#C66882` | 花青 `#5F93A9` | 藤黄 `#D8B469` | 竹青 `#7D9670` | 藕荷 `#9A8EA8` | 赭粉 `#B1785C` | 5.9 → **11.2** |
| 秋山 | 柿红 `#CA6B4D` | 桂黄 `#D1AA55` | 茶绿 `#819767` | 远山 `#5A7A91` | 烟紫 `#A57591` | 栗褐 `#897461` | 6.8 → **10.8** |
| 书斋 | 朱砂 `#BC6665` | 青玉 `#708C7D` | 米黄 `#BCA75F` | 青灰 `#6B8FB6` | 檀褐 `#8F7461` | 雾紫 `#A68FAF` | 5.7 → **10.2** |
| 月夜 | 黛蓝 `#7C87A7` | 月紫 `#A981AB` | 晓青 `#A6B192` | 琥珀 `#D6AC75` | 烟霞 `#AA7D73` | 苍青 `#6B9CA4` | 3.8 → **8.9** |

> 这是**用数值优化得到的候选值**，没有经过视觉审美调校。请你在真实 PDF 上看一遍；若觉得某套偏艳，可以退回原色并把透明度提到 45% 作为折中。宋瓷（默认色谱）建议优先肉眼校对。

3. **色觉缺陷的补偿**（不改色也能做到）：
   - 颜色浮窗里每个色点旁显示**序号 1–6 和名称**；
   - 札记列表条目显示**色点 + 色槽序号**；
   - V1.1 可选"色槽命名"（观点、概念、方法、证据、疑问、补充），这也是原文已经预留的语义标签，对色觉缺陷用户价值最大；
4. 与朱批的区分再加一层**形状**：朱批永远是"框 + 批字 / 图标"，高亮永远是"填充"，不会只靠颜色区分。

## 4. 优化后的完整规格（可替换原文）

### 4.1 目标与原则

保留原文 1.1、1.2 的全部原则，并增加：

- **入口克制**：V1.0 在阅读页内新增的常驻控件为 **0 个**；所有新增能力通过选区工具条、右键菜单、快捷键、⋯ 菜单进入。
- **不打断对读**：任何朱批编辑都不得改变右栏当前标签与滚动位置。
- **可逆**：创建、修改、删除高亮与朱批均可撤销（⌘Z）。
- **不只靠颜色**：所有以颜色区分的信息，必须同时有序号、形状或文字。

### 4.2 命名与信息架构

| 对象 | 中文 | English | 说明 |
|---|---|---|---|
| 高亮 | 高亮 | Highlight | 动作名保持直白 |
| 高亮条目 | **撷英** | Excerpts | 札记中的一类条目；同时也是筛选名 |
| 个人批注 | **朱批** | Margin Note | 基于文字或页面位置 |
| 创建朱批（页面位置） | 落批 | Add Margin Note | 右键菜单与快捷键，不设工具栏按钮 |
| 阅读成果面板 | **札记** | Notes | 右栏标签 |
| 色谱 | 高亮色谱 | Highlight Palette | 文房 › 阅读与外观 |

**右栏标签**：`笺注 | 札记`（两个）。札记中筛选：`全部 | 撷英 | 朱批`。

**不变**：阅读页顶栏仍为 6 个控件（见《阅读页重构方案》第 3.3 节）。

### 4.3 高亮与色谱

**色谱设置**（文房 › 阅读与外观 › 高亮色谱）

- 七套预设，每套 6 色，色值采用第 3.3 节的调整值（或你确认后的最终值）；
- 每套一行：6 个色块 + 中文名 + 英文名 + 一句风格说明；
- 选中即生效，保存为全局默认；默认「宋瓷 Song Porcelain」；
- 透明度滑块：25%–55%，默认 40%，旁边有一行实时预览；
- 说明文字固定：`新建高亮使用此色谱；已有高亮保持原色。`
- 单文献覆盖：**V1.1**。

**创建**

| 方式 | 行为 |
|---|---|
| 选中文字 → 浮窗点 `●`（最近色） | 立即创建 |
| 选中文字 → `▾` | 展开 6 色（带序号与名称），点选创建，并成为"最近色" |
| 选中文字 → 按 `1`–`6` | 直接以该色槽创建（焦点不在输入框、且有文字选区时才生效） |
| 选中文字 → `H` | 以最近色创建 |

**修改与删除**

- 点击已有高亮：弹出小浮层 `[● ● ● ● ● ●] [批] [复制] [删除]`；
- 换色：只改这一条，保留该条的 `palette_id` 更新为当前色谱（其余旧高亮不动）；
- 删除：立即删除并出现 6 秒内的 `撤销` 提示；
- 删除高亮不删除关联朱批（朱批保留自己的锚点）。

**重叠与跨页**

- 同一文字范围允许多条高亮：后创建的在上层，点击取最上层；浮层内提供"此处有 n 条"切换；
- 跨页选区：**拆成每页一个锚点，但共用同一个高亮 ID**；札记中只显示一条，页码显示 `p.5–6`；
- 选区跨栏：按 PDF 文本顺序拆成多个矩形，不使用屏幕拖选框。

**渲染**

- `mix-blend-mode: multiply`，不改变文字颜色，不遮挡图表；
- 随缩放、旋转、DPR 重绘；使用 PDF 页面空间坐标，不使用屏幕像素；
- 色谱变化不触发旧高亮重绘；透明度变化对所有高亮立即生效；
- 无文本层的 PDF（扫描版）：不提供文字选区高亮，选区条不出现；仍允许**落批**。

### 4.4 朱批

**两种创建方式，同一种数据**

| 方式 | 入口 | 锚点 |
|---|---|---|
| 句批 | 选中文字 → 浮窗 `批`，或按 `N` | 文字范围；若选区已完全落在某条高亮内，复用该高亮的锚点，不新建 |
| 旁批 | 右键 › 在此落批；无选区时按 `N`；⋯ › 落批 | 页面坐标（页面宽高的比例，0–1） |

旁批流程：光标变为落批光标 → 点击页面 → 弹出编辑浮层；`Esc` 取消，不产生空记录。

**标记**

| 项 | 规格 |
|---|---|
| 位置 | 句批放在页面外侧最近的**页边**，纵向对齐选区首行；旁批放在点击处，边缘处向内收 |
| 形状 | 方框（1.5px 描边，圆角 3px）；中文界面内为宋体"批"，英文界面内为 `notes` 图标 |
| 尺寸 | 视觉 20px；点击区 32×32px |
| 颜色 | `--jian-vermilion`（浅 `#913E32` / 深 `#E8A28F`），激活态为实心填充、文字反白 |
| 悬停 | 显示前 80 个字符的预览 |
| 聚合 | 相距 < 24px 的标记合并为 `批 ×n`，点击展开列表，逐条可达 |

**编辑浮层（不占用右栏）**

```
┌──────────────────────────────┐
│ 朱批 · 第 5 页                 │
│ “智能生物科技军事化对国际战略…” │  ← 原文引用（旁批无此行）
│ ┌──────────────────────────┐ │
│ │ 在这里写下你的想法…          │ │  ← 纯文本，最多展开到 8 行
│ └──────────────────────────┘ │
│ 已保存            在札记中查看  删除 │
└──────────────────────────────┘
```

- 纯文本；V1.0 无富文本、无 Markdown 渲染；
- 输入 600ms 后自动保存；草稿存于本地状态，切换原文/对读、关闭浮层、切换标签均不丢失；
- 空内容：`Esc` 或点击外部时，若是新建则不保存；若是已有朱批被清空，提示是否删除；
- 浮层位置：贴近标记，空间不足时翻转；窗口窄于 1100px 时居中显示；
- 键盘：`⌘↩` 保存并关闭，`Esc` 关闭，焦点陷阱，关闭后焦点回到标记；
- "在札记中查看"：右栏切换到札记并定位该条，**这是用户主动操作**，不是点击标记的副作用。

### 4.5 札记

- 右栏第二个标签，内容为当前文献阅读成果的统一视图；
- 顶部筛选：`全部 · 撷英 · 朱批`，每项后带数量；
- 排序：按页码，同页按 PDF 文本顺序；
- 条目结构：

```
p.5                                   ● 1 · 天青
┃ 智能生物科技军事化对国际战略稳定构成冲击…      ← 原文引用（带高亮色的 3px 左线）
  （已有译文时，显示一行辅助灰的译文）
  批：这里的论断需要和第三节对照。            ← 朱批正文（若有）
                                  回到原文 · 复制 · 删除   ← 悬停才出现
```

- 点击条目：PDF 滚到对应位置并短暂闪现 600ms；
- 纯高亮条目没有正文行；不创建空笔记；
- 空状态：`选中文字高亮，或按 N 写一条朱批。` / `Select text to highlight, or press N to write a margin note.`
- 全文札记：V1.1，关联整篇文献，`anchor_id = NULL`。

### 4.6 数据模型

**先查现状**：检查仓库里的 `annotation`、`note`、`PdfAnchor`、`document_version`、`reading_state`、`translation_record` 是否已落地，能复用就复用，下面是最小结构的**目标形态**。

```sql
-- 锚点（文字范围或页面位置）
anchor(
  id, document_version_id, page_index,
  kind            TEXT CHECK (kind IN ('text','point')),
  rects_json      TEXT,   -- text：PDF 页面空间（未旋转）中的矩形数组
  point_x REAL, point_y REAL, -- point：页面宽高比例 0..1
  quote TEXT, prefix TEXT, suffix TEXT,  -- 文件被替换后用于"提示确认"
  order_key       INTEGER -- (页码, 文本项序号) 的复合排序键
)

-- 高亮
highlight(
  id, anchor_id, palette_id, slot_index, hex,   -- 不存透明度
  created_at, updated_at, deleted_at
)

-- 笔记（朱批正文）
note(
  id, document_id, anchor_id NULL, highlight_id NULL,
  body TEXT NOT NULL CHECK (length(trim(body)) > 0),   -- 数据层禁止空笔记
  created_at, updated_at, deleted_at
)

-- 札记 = 数据库视图，不建表
CREATE VIEW reading_items AS
  SELECT ... FROM highlight h LEFT JOIN note n ON n.highlight_id = h.id
  UNION ALL
  SELECT ... FROM note n WHERE n.highlight_id IS NULL;
```

关系规则：

- 一个文字范围可有 0..1 条高亮、0..n 条朱批；
- 对已高亮范围加朱批：`note.anchor_id = highlight.anchor_id`，`note.highlight_id = highlight.id`；
- 软删除（`deleted_at`）支撑撤销；永久清除跟随回收站规则；
- 全文索引覆盖 `note.body` 与 `anchor.quote`；
- **禁止**同时出现第二套朱批正文存储。

**锚点要求**（沿用原文并补充）：

- 一律存 PDF 页面空间坐标，且为**未旋转**坐标，渲染时再按旋转与缩放变换；
- 重新打开、缩放 50%–400%、旋转 0/90/180/270、DPR 1/2/3 后位置一致；
- PDF 文件被替换：不自动迁移；按引文+前后文给出"可能的新位置"，由用户确认。

### 4.7 键盘与焦点

| 操作 | 键 | 条件 |
|---|---|---|
| 以色槽 n 高亮 | `1`–`6` | 有文字选区、焦点不在输入框 |
| 以最近色高亮 | `H` | 同上 |
| 写朱批 | `N` | 有选区→句批；无选区→进入落批模式 |
| 撤销/重做 | `⌘Z` / `⌘⇧Z` | 阅读页内，覆盖创建、改色、删除 |
| 保存并关闭朱批浮层 | `⌘↩` | 编辑浮层内 |
| 在页内按顺序切换标记 | `Tab` / `⇧Tab` | 焦点在 PDF 区域 |
| 关闭浮层/退出落批 | `Esc` | — |

所有图标按钮有 tooltip（含快捷键）和 `aria-label`；标记的可访问名称为 `朱批，第 5 页：<首句>`。

### 4.8 搜索、导出、备份、Zotero

**搜索（考索）**：结果中增加类型标记 `撷英 / 朱批`，覆盖 `note.body` 与 `anchor.quote`；点击结果打开阅读页并定位到锚点。

**导出（V1.0）**：札记面板 ⋯ › `导出为 Markdown` / `复制全部`；可对筛选结果或选中条目导出。模板：

```markdown
# 人工智能时代的生物安全治理：困境及路径
高望来 · 阅江学刊 · 2026 · DOI 10.13878/j.cnki.yjxk.2026.02.005
导出于 2026-10-30 · 笺 Glossleaf

## 第 5 页

> 智能生物科技军事化对国际战略稳定构成冲击……
> （译文，若有）

**批：** 这里的论断需要和第三节对照。
`色谱：宋瓷 · 槽 1 天青`
```

其他格式（Word、PDF、CSV）放 V1.1。文献交换格式（BibTeX 等）**不**承载批注，也不得宣称可无损恢复。

**备份**：色谱偏好、`anchor / highlight / note`、阅读状态进入完整备份；迁移脚本可重复执行；恢复后做逐条比对（数量、正文、锚点矩形、色值）。

**Zotero**：导入的高亮保留来源色，`palette_id = 'zotero'`，`hex` 为来源色；Zotero 评论转为 `note`，关联到对应高亮；暂不支持编辑的富文本笔记继续原始载荷保留与只读展示；图片/墨迹类注释保留原始数据，不转换。

### 4.9 视觉规范

| 项 | 规格 |
|---|---|
| 朱批色 | `--jian-vermilion`，不另定义固定 hex |
| 高亮色 | 运行时由"当前色谱 + 槽位"解析，不进入静态 token；旧高亮用自身保存的 `hex` |
| 札记面板底色 | `--jian-paper`，不新增"旧绢白"；与整个应用一致 |
| 字体 | 不采纳品牌规范的字体；"批"字使用系统自带的 Songti SC；笔记正文 PingFang SC 14/22；中英混排不得出现基线错位 |
| 动效 | 浮层 120ms 淡入；定位闪现 600ms；尊重"减少动态效果" |
| 对读联动 | **不再使用淡青底**（会与青色系高亮混淆）；PDF 上只保留页边 2px 青线，参见第 5 节 |
| 深色界面 | PDF 页保持白底，高亮 `multiply`；PDF 反色模式如启用，高亮改 `screen` 并单独验证 |

### 4.11 验收标准（量化版）

**色谱**

- [ ] 七套色谱各 6 色，值与最终确认表一致；
- [ ] 40% 透明度下，每套色谱最近两色 ΔE2000 ≥ 8；
- [ ] 每套色谱的基础色与朱批色 ΔE2000 ≥ 14；
- [ ] 墨色正文在最大透明度（55%）高亮上的对比度 ≥ 4.5:1（实测 45% 时 ≥ 8.6:1）；
- [ ] 切换色谱后，新高亮用新色、旧高亮颜色保持（逐条比对 `hex`）；
- [ ] 透明度改变后，所有高亮即时变化，数据库无写入。

**锚点与渲染**

- [ ] 缩放 50% / 100% / 200% / 400%：高亮与标记相对文字的偏移 ≤ 1 设备像素；
- [ ] 旋转 0/90/180/270，DPR 1/2/3 均通过；
- [ ] 测试集至少 5 份 PDF：单栏中文、双栏英文、含公式、含图表、扫描版（无文本层）；
- [ ] 双栏 PDF 中跨栏选区不产生跨栏矩形；
- [ ] 重新打开文献、重启应用后，数据与位置一致。

**交互**

- [ ] 新增高亮从选区到出现 ≤ 100ms；
- [ ] 一篇含 500 条标注的文献，打开耗时增加 ≤ 150ms；
- [ ] 输入朱批时，切换原文/对读、关闭浮层、切标签后，草稿 100% 保留；
- [ ] 点击朱批标记**不改变**右栏标签与滚动位置；
- [ ] 数据库中不存在 `body` 为空的 `note`；
- [ ] 创建、改色、删除高亮与朱批均可 ⌘Z 撤销，撤销后与操作前一致；
- [ ] 相邻 5 条标记聚合后，每条都能通过列表打开。

**数据安全**

- [ ] 备份恢复后条数、正文、锚点矩形、`hex` 逐条一致；
- [ ] Zotero 导入的高亮保持来源色，评论转为笔记且不丢失；
- [ ] 原 PDF 文件的哈希值在全流程前后不变；
- [ ] 迁移脚本重复执行 3 次结果一致。

**可访问性**

- [ ] 仅键盘可完成：创建高亮、写朱批、在标记间切换、关闭浮层；
- [ ] 色觉缺陷模拟下，每条高亮在列表与浮窗里都能通过序号/名称识别；
- [ ] 减少动态效果设置下无位移动画。
