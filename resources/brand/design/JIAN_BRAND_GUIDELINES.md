# 笺 Jian · 品牌与视觉资源规范 v1.0

> 本交付包依据 `笺 Jian · 产品与设计开发方案 v3.0` 制定，专注 **品牌识别、名称译名、色彩、图标与排版原则**，**不包含页面布局、页面线框、整页效果图或新增功能设计**。
> 交付日期：2026-10-29。具体 UI 功能、版本和发布门槛，仍以原开发文件为准。

## 一、定位

**中文品牌：笺**；**英文品牌：Jian**（不另造英文商标名）。

产品主张沿用开发文档：**让外文文献读得下去，让读过的内容找得回来。**

品牌短句（提议，不取代产品主张）：**让阅读有所解，让思想有所存。**

英文品牌短句：**Read deeply. Keep what matters.**

关键词：*纸墨、编目、页边、沉静、准确、当代学术出版物*。古典感通过命名、编辑排版、文字层级和朱色小标记实现，不依靠宣纸纹理、传统纹样和大量装饰。

## 二、功能命名与易懂英文（正式）

| 层级 | 标识 | 中文 | English | 说明 |
|---|---|---|---|---|
| 主工作区 | library | **书府** | **Library** | 文献、附件、集合、标签、元数据；对应开发文档“文库” |
| 阅读工作区 | reader | **展卷** | **Reader** | 原 PDF 阅读、目录、缩放、阅读位置 |
| 阅读模式 | bilingual | **对读** | **Bilingual Reading** | 原文+译文段落联动；短控件可用 Bilingual |
| 阅读成果 | excerpts | **撷英** | **Excerpts** | 原文、译文、页码与锚点的摘录 |
| 阅读成果 | notes | **札记** | **Notes** | 评论、笔记与个人判断 |
| 工具 | search | **考索** | **Search** | 全库检索、正文与摘录命中、回到原文 |
| 文库工具 | collections | 编帙 | Collections | 集合树 |
| 阅读工具 | translate | 笺释 | Translate | 选区和段落翻译；操作命令仍写“翻译本页” |
| 阅读工具 | glossary | 释名 | Glossary | 术语表 |
| 文库工具 | details | 著录 | Details | 文献信息及元数据 |
| 文库工具 | citations | 征引 | Citations | 引用生成/复制 |
| 数据操作 | import | 收录 | Import | PDF、Zotero、DOI 导入 |
| 数据操作 | backup | 留存 | Backup & Restore | 备份与恢复 |
| V1.1 | bilingual | 夹注 | Inline Translation | 单栏行间模式通过专项验证后启用 |

**约束：** 它们是词汇体系，**不是** 新增 6 个平行导航。结构保留开发文档的“文库 → 阅读标签页 → 设置”；“对读”是阅读模式，“考索”是搜索功能，“撷英/札记”是上下文面板。

**本地化原则：** 中文层级标题允许文雅词汇，英文一律先保证能被第一次使用者理解。译名不是逐字翻译，如“撷英→Excerpts”。危险或恢复性操作不使用隐喻替代标准操作词（“永久删除 / Delete Permanently”“恢复备份 / Restore Backup”）。回收站统一为“回收站 / Trash”，不用“归藏”。

## 三、五色体系

传统色的意象用于命名，HEX 是现代屏幕色值，不当作考据意义上的唯一标准色。

| 色组 | Light | Dark | 使用原则 |
|---|---|---|---|
| 玄墨 Ink | `#22221F` | `#E9EBE4` | 一级文字、主按钮、编目、搜索 |
| 宣米 Paper | `#F8F7F3` | `#1B1D1A` | 应用基础表面；PDF 原件保留自身颜色 |
| 朱砂 Vermilion | `#913E32` | `#E8A28F` | 品牌记号、个人评论/札记 |
| 黛青 Teal | `#386874` | `#9BCBD0` | 翻译、双语段号、术语相关关系 |
| 藤黄 Ochre | `#B78D3B` | `#E5C67A` | 摘录收藏、重点高亮；浅色模式小字使用 `#8D6A22` |

辅色：浅色 `#FFFEFB`（抬升面）、`#F0EEE8`（凹陷面）、`#DADBD3`（线）。浅色的淡青/淡朱/淡黄分别为 `#E9F1F0`、`#F7EBE7`、`#F7EDCE`。具体 token 在 `design/tokens.css`。

**色彩语义：**

- 墨+米占绝大部分阅读面积；朱、青、黄只标记真正有语义的行为。
- 朱 = 用户所写；青 = 原译对应；黄 = 值得保存的原文；墨 = 系统组织和检索。
- “对读”译文是正常墨色正文，**不应**让整栏正文变青。
- 搜索结果可用淡黄高亮命中，但搜索本身归墨色工具。
- 导入的第三方彩色标注保留来源色；不强制全部替换成品牌色。
- 不能仅凭颜色传达错误/完成状态。错误文字、按钮及图标与主题色分离。
- `#B78D3B` 作为浅色底上的小字对比度不足，浅底文字改 `#8D6A22`，并通过对比测试。

## 四、品牌应用图标

图形概念：**一张展开的书页 + 一段朱色页边标记**。开放文页暗示阅读，短朱记号暗示笺注，米/墨体现纸张与典藏。

交付：`icons/app/jian-app-{light|dark}-{master|micro}.svg`，及 16/32/128/512px PNG。主图标用于普通尺寸；微型版删除次要横线，保证小尺寸识别。

图标不使用复杂中文印刷字作为主符号；中文单字“笺”保留在关于页和宣传字标中。正式发行前需核验 macOS 图标遮罩、深浅模式实际观感、16px Dock 尺寸。

## 五、功能图标 Jian Marks

SVG 统一为 24×24 viewBox、1.75 stroke、round linecap/linejoin、`currentColor`，不内置语义颜色。不同场景通过 CSS token 控制。**如需由父级 CSS `color` 驱动图标，需将 SVG 以内联 SVG / React SVG 组件方式导入；以 `<img src="...svg">` 载入时，父级 `color` 通常不会传入 SVG 文档。**

- **核心六项：** library / reader / bilingual / excerpts / notes / search，见 `icons/core/`。
- **工具图标：** collections / glossary / details / citations / import / export / backup / back-to-source / translate / trash / highlight / settings，见 `icons/utility/`。
- 图标在导航或工具栏中默认为墨色，激活时才允许依据语义出现朱、青、黄。不要将六张不同色图标直接当成永远保持彩色的工具栏。
- 24px 原稿在界面中通常显示 18–20px；常规按钮命中区至少 32×32px。所有图标功能必须有可见标签或可访问名称。
- 品牌 App Icon 与功能图标分开管理，前者彩色，后者 SVG `currentColor`。

## 六、字体

- 品牌中文“笺”与主要文化性标题：Source Han Serif SC（思源宋体）或合法授权的同类宋体。
- 英文品牌/大标题：Source Serif 4 / Georgia 作为候选，按实际包环境与授权核验；英文界面按钮与系统菜单维持系统 UI 字体。
- 常规中文、译文、标签：macOS 系统字体或 Source Han Sans SC（思源黑体）。
- 页码、段号、键盘快捷键：系统等宽字体。
- 保留开发文档默认译文 **16px / 28px**，不以文化装饰替代阅读舒适度。
- **此包不附带任何字体文件**；实现时从字体官方渠道获取并遵守许可。

## 七、落地与验收

1. 先确认品牌名称、6 个功能名称、颜色语义与 App Icon 原型。
2. 将 `design/tokens.css` 映射到既有设计系统，保留文档中已定义的响应式与可访问性要求。
3. 将 `locales/zh-CN.json` / `en-US.json` 接入 i18n，不对产品界面内的长标题强求同字数。
4. 使用 SVG `currentColor` 图标。采用单色状态和功能激活色测试，不在普通工具栏强制彩色。
5. 验证浅/深主题的文字/图标对比度，以及 16/32/128/512px App Icon 的辨识度。
6. 完整依据开发文档 V3.0 的原功能闭环与 V1.1 发布门槛，不因为品牌升级擅自增加新模块。

## 八、非交付范围

不交付页面布局、线框、窗口结构改造、阅读器整页 mockup、完整前端实现、可安装 `.app`、官方商标/可注册性结论。此包中的 SVG 属于**可直接修改的视觉初稿**，仍需在产品的实际缩放、深色和无障碍环境下验证。
