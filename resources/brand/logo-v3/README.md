# 笺 · Glossleaf | Logo Colorways v3.0

## 设计取舍

- 移除上一版位于主体上方的 **两片分离小叶**，不再模拟竹字头。
- 保留一笔式主叶与较窄的第二色叶缘，墨与朱之间是真实透明留白（非背景色遮罩）。
- 左侧主形代表原文/书页，右侧较窄形代表页边朱批；留白既是叶脉，也呼应纸页折线。
- 无描边、渐变、纹理、阴影。文字符号与图形分开：中文 UI 推荐使用 **图形＋笺**，英文 UI 使用 **图形＋Glossleaf**。

## 文件结构

- `svg/`：六套 × 浅色/深色，均为透明背景 SVG。
- `png/`：对应 16、20、24、32、64、128、256、512px 透明 PNG。
- `app/`：六套 × 浅色/深色的满铺应用图标 SVG + 32/128/256/512/1024px PNG。
- `preview/`：方案对比、六色总览、顶栏 20px 示例、深色模式示例。
- `developer/logo-palettes.json`：配色数据，可在设置中作为 Logo 风格选项。
- `developer/GlossleafMark.tsx`：React inline SVG，支持 `palette`, `dark`, `size`。
- `developer/glossleaf-logo.css`：建议的基础对齐样式。

## 开发接入规则

1. 将图形视为 **品牌图标**，与阅读功能颜色体系保持独立：用户变更 Logo 风格，不影响朱批、高亮和译文语义色。
2. 默认 Logo 尺寸建议 20px；标题栏组合区 32px 高，图形与标题之间 8px。
3. 主题切换时，对当前方案自动使用相应暗色图形。用户只需选择 A–F，不必分别选择日间、夜间。
4. `zh-CN` 品牌文字为 `笺`，`en-US` 品牌文字为 `Glossleaf`，不在 20px logo 内挤入英文名。
5. 16px 版本视觉上两色分界可能弱化；用于 favicon 可考虑单色变体，不保证所有低分辨率设备效果一致。
6. 图标字标使用用户系统可用字体（例如 Songti SC）；没有授权的字体请不要复制和打包。
7. 建议真实 macOS 运行中检查标题栏 1×/2× 渲染、暗色与高对比度模式，App 图标按发布要求另行验证。

## 本轮未做

没有修改真实项目源码或应用设置；没有执行 macOS 原生桌面环境的图标审核。所有顶栏呈现仅是视觉示例。
